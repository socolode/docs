# Store Setup

Configure your store settings before going live.

## Store profile

Navigate to **Settings > Store Profile** to set your store identity.

### Basic information

- **Store name**: Displayed in the navbar, footer, and browser tab
- **Logo**: Upload a PNG or SVG, recommended size 200x200px
- **Favicon**: 32x32px icon shown in the browser tab
- **Store description**: 160-character summary used in search results and social sharing

### Contact details

Set the email and phone number that customers see on order confirmations and contact pages. These also appear in transactional emails sent by the platform.

## Currency and taxes

Under **Settings > Currency**, select your default store currency. Socolode supports multi-currency display for international customers.

For taxes, navigate to **Settings > Taxes** to configure:

- Automatic tax calculation based on customer location
- Manual tax rates for specific regions
- Tax-inclusive vs tax-exclusive pricing

## Shipping zones

Define where you ship and how much it costs under **Settings > Shipping**.

1. Create a shipping zone (e.g., "Domestic" or "International")
2. Add countries or regions to the zone
3. Set a shipping rate: flat rate, weight-based, or free shipping threshold

## Staff accounts

Invite team members under **Settings > Staff**. Each staff account has a role:

- **Admin**: Full access to all settings and data
- **Staff**: Can manage products and orders, cannot change billing
- **Developer**: Access to API keys and theme code only

## Notification preferences

Under **Settings > Notifications**, choose which events trigger an email or in-app alert:

- New order received
- Low stock warning (set threshold per product)
- Customer signup
- Payment failure
