## Instructions

1. Click the **"Open Online Tool"** button above to navigate to the tool page
2. Upload the image you want to process (JPG, PNG, etc.)
3. Select the output pixels based on your wand specification (144 / 192 / 240 / 288 / 480, etc.)
4. Adjust parameters such as brush direction, natural saturation, black/white levels
5. Click download to get a ZIP file containing BMP + JPG
6. Rename the BMP file to numbers or English characters, and place it in the wand's `/sd/image` directory

:::tip Privacy
All images are processed locally in your browser. Nothing is uploaded to any server. Safe to use!
:::
