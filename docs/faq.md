# FAQ

## Getting started

### How long does it take to set up a store?

Most users can create an account, add products, and launch within **30 minutes**. Custom domain setup adds 10-15 minutes for DNS configuration, with propagation taking up to 48 hours.

### Do I need coding skills?

No. The visual theme editor and product management dashboard require no coding. Coding is only needed for API integration or advanced theme customization.

### Can I migrate from another platform?

Yes. Socolode supports CSV imports from Shopify, WooCommerce, and BigCommerce. Navigate to **Products > Import** and select your platform for a guided migration.

## Billing

### When am I billed?

Subscription fees are charged monthly on the date you signed up. Transaction fees (if any) are deducted from each payout.

### Can I change plans mid-cycle?

Yes. Upgrades take effect immediately and you are charged the prorated difference. Downgrades take effect at the next billing cycle.

### What payment methods do you accept for subscription fees?

Visa, Mastercard, American Express, and PayPal.

## Products and inventory

### Is there a limit on product images?

Each product supports up to 10 images. Recommended size is 2000x2000px, maximum file size 5MB per image. Accepted formats: JPG, PNG, WebP.

### Can I sell digital products?

Yes. Upload your digital file (PDF, ZIP, MP3) under the product's **Digital Asset** section. Customers receive a download link after payment.

### How does inventory sync work across channels?

If you sell on multiple channels (your store, social media, marketplaces), inventory is synced in real-time. When a product sells on one channel, stock decreases everywhere.

## Shipping and taxes

### Which carriers do you integrate with?

UPS, FedEx, DHL, USPS, SF Express, and China Post. Real-time rate calculation is available for all integrated carriers.

### How are taxes calculated for international orders?

Socolode uses the customer's shipping address to determine applicable taxes. For cross-border orders, import duties may apply and are calculated at checkout when using DDP (Delivered Duty Paid) shipping.

## Customization

### Can I edit the theme code directly?

Yes. Under **Online Store > Themes > Edit Code**, you have full access to the theme's HTML, CSS, and JavaScript files. Changes are version-controlled and can be rolled back.

### Can I use my own domain?

Yes, on the Growth plan and above. Connect a custom domain under **Settings > Domains**. SSL certificates are provisioned automatically.

### Do you support multi-language storefronts?

Yes. You can create translations of your store content (product descriptions, page content, navigation) for up to 20 languages. The documentation itself is bilingual and maintained as a single source.
