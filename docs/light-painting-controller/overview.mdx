# LightCoding Series Overview

The Socolode LightCoding series is a line of light controllers ranging from compact entry-level to professional handheld form factors. Whether you're a light painting enthusiast, a desktop ambiance creator, or an interactive light installation artist, there's a controller for you.

---

## Product Lineup

### Firefly T1

A palm-sized light control host, lightweight and portable, perfect for beginners and on-the-go creation.

- **Form**: Compact square host with built-in screen and 5-way joystick
- **Power**: Built-in 18650 Li-ion battery, Type-C charging
- **Use cases**: Outdoor light painting, desktop ambiance, party decoration
- **Highlights**: Plug and play, no coding required, 5-minute setup

-> <Link to="../light-painting-controller/firefly-t1/product-intro/what-is-this">Learn about Firefly T1</Link>

### Beetle S1

An ergonomic handle-shaped professional handheld light controller with an integrated design, ideal for professional creative work and extended use.

- **Form**: Handle-shaped all-in-one body with built-in circular color screen and physical buttons
- **Power**: Dual Type-C (fast-charge + data port), high-current XT30 output
- **Use cases**: Professional light painting, large light installations, interactive installations
- **Highlights**: High power output, 4-pin expansion port, ergonomic grip

-> <Link to="../light-painting-controller/beetle-s1/product-intro/what-is-this">Learn about Beetle S1</Link>

---

## Shared Features

Both controllers share these core capabilities:

- **Plug and Play**: Drag-and-drop effect files via USB mass storage mode - no soldering or coding required
- **Open Source & Programmable**: Based on MicroPython ecosystem, supports custom API for writing light effects
- **LED Strip Compatibility**: Supports common WS2812 LED strips and rings
- **Endless Creativity**: From light painting photography to desktop clocks, from rhythm lights to interactive installations
- **Community Sharing**: Continuously updated effect library and community-shared creative ideas

## How to Choose?

**Choose Firefly T1 if:**
- You're new to light controllers and want an easy start
- You need a compact device for portability and anytime creativity
- You're on a budget but want the full light creation experience

**Choose Beetle S1 if:**
- You need extended handheld creative sessions - the ergonomic handle design is more comfortable
- You need to drive high-density long LED strips or large light installations
- You want to connect sensors via the 4-pin expansion port for interactive installations
