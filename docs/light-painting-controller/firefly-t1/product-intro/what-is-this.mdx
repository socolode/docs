# Firefly T1 Product Introduction

## What Is This?

Firefly T1 sits between a traditional development board and a finished product. It can run standalone or be paired with various accessories for diverse use cases, designed for creative lighting projects. Install the battery and it works; plug into a computer and files transfer instantly. Drag in a file to switch effects, tweak a few numbers to adjust settings — no experience needed. Know how to code? Write a script to take full control of any lighting pattern.

## More Creative Projects

### Time Ring

Put on a light ring and Firefly T1 becomes a desktop clock. Display time, countdown, pomodoro timer — both a practical tool and a desktop decoration.

**You need:** Firefly T1 + Light ring

See the <Link to="../effects-projects/creative-projects/time-ring">Time Ring Guide</Link> for detailed instructions.

### Desktop Rhythm Light

The light ring pulses with music, changing colors and brightness based on audio frequency. Place it on your desk for the most eye-catching ambient light.

**You need:** Firefly T1 + Light ring + Audio source

See the <Link to="../effects-projects/creative-projects/rhythm-light">Rhythm Light Guide</Link> for detailed instructions.

### Ambient Light Wall

Connect multiple light strips to create an immersive lighting environment. Customizable color gradients and breathing effects, perfect for live streaming, studios, and parties.

**You need:** Firefly T1 + Multiple light strips

## Highlights

### Compact & Portable

- Powered by built-in 18650 Li-ion battery, no cable tethering
- Type-C charging, share cables with your phone
- Barely heavier than a single 18650 battery

### Plug & Play

- Drag-and-drop effect installation via USB drive mode
- Five-way joystick for quick effect switching
- Supports LED strips and rings

### Open-Source & Programmable

- Complete custom API
- Built on MicroPython, rich community ecosystem
- Open-source firmware with regular updates

### Unlimited Creativity

- Compatible with common WS2812 LED strips and rings
- 3D printable enclosure for personalized looks
- Community-driven effects and project sharing
