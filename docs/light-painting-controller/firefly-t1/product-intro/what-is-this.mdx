# What Is This?

Firefly T1 is a palm-sized light control host. Attach a light strip and it becomes a light painting stick; put on a light ring and it becomes a desktop clock or rhythm light. Drag a file in to switch effects, adjust a few numbers to change colors and speed. Know Python? You can even write your own effects.

This is not a development board that needs soldering — install the battery and it's ready to go, plug it into a computer to transfer files. No programming skills required.

## What's in the Box

| Item | Description |
|------|-------------|
| Firefly T1 Host | Light controller with built-in screen and 5-way joystick |
| 5P Interface Cable | For connecting light strips or light rings |
| Type-C Cable | For charging and connecting to PC |
