# Install Your First App

Get your Firefly T1 glowing in 5 minutes.

## Step 1: Download an App

Open the [**Apps Directory · GitHub**](https://github.com/socolode/firefly-t1/tree/main/apps), choose an app and download it.

## Step 2: Connect to PC

Connect Firefly T1 to your computer via USB. After a few seconds, a new USB drive will appear.

## Step 3: Drag and Drop

1. Open the USB drive and find the `/apps` folder
2. Drag the downloaded app file into `/apps`
3. Open `/apps/config.json` with a text editor and add the new app info

## Step 4: Enjoy!

1. Safely eject the USB drive and unplug the cable
2. Power on, toggle left/right to select the new app
3. Press center button — the lights come on!

For detailed installation instructions, see <Link to="../apps-play/app-list-install">App Installation</Link>.
