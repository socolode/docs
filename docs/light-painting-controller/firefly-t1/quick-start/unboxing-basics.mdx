# Unboxing & Basic Operations

## What's in the Box

| Item | Description |
|------|-------------|
| Firefly T1 main unit | Built-in screen and five-way joystick |
| 5P interface cable | For connecting LED strips or rings |
| Type-C cable | Charging and computer connection |

:::note
Firefly T1 does not include a 18650 battery. Please purchase separately.
:::

## Install Battery

1. Open the battery compartment cover on the back
2. Insert a 18650 Li-ion battery, observing polarity

:::caution
Incorrect battery polarity will prevent the device from powering on.
:::

## Charging

Connect the included Type-C cable to a charger or computer.

- Charging indicator LED next to the Type-C port
- 5V/1A+ charger recommended, about 2-3 hours for a full charge
- Compatible with phone chargers and power banks

## Power On & Off

**Power On**
1. With the device off
2. Press and hold the joystick center button for 2 seconds

**Power Off**
1. Exit all effects and return to the home screen
2. Press the joystick down button once

![Joystick diagram](../assets/firefly-t1-02.png)

## Enter & Exit Effects

**Enter Effect**
1. Move the joystick left/right to select an effect
2. Press the center button to enter

**Exit Effect**
1. While in an effect
2. Press and hold the center button for 2 seconds to return to home

## Connect to Computer

When connected via USB, a new USB drive appears. Use it to transfer effect files and manage data.

:::tip
If no USB drive appears, ensure your USB cable supports data transfer (some charging cables don't).
:::

## Notes

- Safe to store when powered off, no need to remove the battery
- When plugged in, automatically switches to external power mode
- Use the included cable for best charging and data transfer performance
