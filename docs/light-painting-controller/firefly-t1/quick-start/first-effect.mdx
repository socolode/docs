# Install Your First Effect

Get your Firefly T1 glowing in 5 minutes.

## Step 1: Download an Effect

Open the <Link to="../effects-projects/effect-list-install">Effects & Installation</Link>, choose a light effect and download it.

## Step 2: Connect to PC

Connect Firefly T1 to your computer via USB. After a few seconds, a new USB drive will appear.

## Step 3: Drag and Drop

1. Open the USB drive and find the `/apps` folder
2. Drag the downloaded effect file into `/apps`
3. Open `/apps/config.json` with a text editor and add the new effect info

## Step 4: Enjoy!

1. Safely eject the USB drive and unplug the cable
2. Power on, toggle left/right to select the new effect
3. Press center button — the lights come on!

For detailed instructions, see <Link to="../effects-projects/effect-list-install">Effects & Installation</Link>.
