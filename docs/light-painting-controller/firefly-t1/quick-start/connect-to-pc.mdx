# Connect to PC

## USB Drive Function

After connecting the device to your computer with a data cable, a new USB drive will appear. You can use it to update App programs or read and write files.

## How to Connect

Use the included Type-C data cable to connect Firefly T1 to a USB port on your computer:

![Connect to PC diagram](../assets/firefly-t1-20.png)

## USB Drive

Once connected successfully, you will see a new USB drive letter in your computer's file explorer:

![USB drive display diagram](../assets/firefly-t1-21.png)

You can directly read and write files on the USB drive, for example:
- Copy new App scripts to the USB drive
- Export log files from the device
- Back up or update configuration files

## Notes

### About Charging

- You can use a phone charger or power bank to charge the device
- The device can be stored directly after power off, no need to remove the battery
- After plugging in the power, it automatically switches to external power supply; the device can work normally even without a battery installed

### About Data Cable

- To ensure charging power and data transmission stability, it is recommended to use the original matching data cable
