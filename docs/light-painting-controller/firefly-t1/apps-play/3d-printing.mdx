# 3D Printed Enclosure

## Download Model Files

Firefly T1 3D enclosure model files are hosted in the official GitHub repository — browse and download directly:

[Firefly T1 3D Models Directory · GitHub](https://github.com/socolode/firefly-t1/tree/main/3d-models)

Models are organized by use case:

- `3d-models/case/` – Main unit enclosure (STL + STEP source files)
- `3d-models/time-ring/` – Time Ring light stand and ring structural parts
- `3d-models/accessories/` – Clamps, handles, stands, diffusers, and other accessories

## Printing Tips

- **Material**: PLA recommended for enclosures, PETG or ABS for load-bearing accessories
- **Layer height**: 0.2mm delivers a good balance of finish and speed
- **Supports**: Enable supports for overhanging features when needed
- **Infill**: 15%–20% infill is sufficient for everyday use

## Assembly Guide

1. Clean up support material and rough edges after printing
2. Insert the Firefly T1 main unit into the enclosure
3. Secure with screws (if your case design calls for them)
4. Plug in the LED strip / ring and you're ready to go

## Customization

If you have 3D modeling experience, feel free to remix the STEP / Fusion source files in the repo to create a one-of-a-kind look. Contributions back to the official repository via PR are always welcome!
