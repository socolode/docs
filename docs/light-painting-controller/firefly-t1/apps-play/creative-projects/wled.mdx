# WLED

:::

## What Is WLED

**WLED** is a hugely popular open-source LED control firmware (runs on ESP32 / ESP8266 and similar chips). Widely adopted by the global DIY community, it's the de-facto standard tool for addressable LEDs. Highlights:

- **200+ built-in animation effects** — classic animations, audio-reactive effects, 2D matrix effects, and more
- **Segmented control** — split a single LED strip into independently colored segments, each with its own effect
- **Presets & playlists** — one-click scene switching with schedules and triggers
- **Web UI + mobile app** — adjust colors and switch effects directly from your browser or phone, no coding required
- **Multi-protocol support** — native E1.31 (sACN), Art-Net, DDP, MQTT, and Home Assistant integration
- **Huge community** — rich ecosystem of custom usermods, tutorials, and third-party controllers

## What You'll Get With Firefly T1 + WLED

Once integrated, you'll be able to use the full WLED ecosystem on your Firefly T1, such as:

- Real-time color adjustment and effect switching via WLED's web UI or mobile app
- Smart home integration (Home Assistant, Apple HomeKit, Alexa, and more)
- Acting as an E1.31/Art-Net pixel node driven by professional lighting software (xLights, Jinx!, Vixen, etc.)
- Advanced modes like audio-reactive effects, preset playlists, and segment layering
