# Firmware Update & System Flashing

## Check Firmware Version

On power-up, the current firmware version is displayed on the home screen. If you encounter issues or want to try new features, consider updating the firmware.

## Firmware Download

Latest firmware files are available here:

[Firefly T1 Firmware - Baidu Pan](https://pan.baidu.com/s/19I89DSC0XkglKS-24e6vkA?pwd=j99s)

## Update Steps

### Method 1: Flash via Thonny

1. Install Thonny IDE
2. Download the firmware
3. Flashing steps:
   - Power off, hold the joystick "right" button
   - Connect USB to computer
   - Open Thonny and configure the interpreter
   - Click "Install/Update MicroPython"
   - Select the firmware file and COM port

![Thonny Flash](../assets/firefly-t1-12.png)

![Flash Settings](../assets/firefly-t1-15.png)

### Method 2: Flash via Command Line

1. Open command line (Thonny Tools -> Open System Shell)
2. Enter the flash command

![Command Line Flash](../assets/firefly-t1-16.png)

:::caution
If the COM port is not detected, you may have forgotten to hold the "boot" button while connecting USB.
:::

## Update Tips

- Ensure battery is sufficiently charged before updating
- Use the latest stable firmware unless you need specific features
- You can revert to a previous version if needed
