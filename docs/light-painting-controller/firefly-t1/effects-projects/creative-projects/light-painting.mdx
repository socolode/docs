# Light Painting

Connect an LED strip to your Firefly T1 and paint with light in the night sky, creating stunning light trail photos.

## What You Need

- Firefly T1 main unit
- WS2812 LED strip (144/m recommended)
- Tripod
- Camera or phone with manual mode (long exposure support)
- Dark environment

## Preparation

1. Follow the <Link to="../compatible-leds-wiring">wiring guide</Link> to connect the LED strip
2. Install a light painting effect file
3. Set camera: Manual mode, shutter 2-30s, ISO 100-400, aperture f/8-f/11
4. Find a dark environment

## Shooting Tips

### Basic Light Painting

Use the Firefly T1 + LED strip as a brush. During the shutter open time, the LED trails will be recorded in the photo.

### Creative Light Painting

- **Multi-color trails**: Use gradient effects for color-changing trails
- **Text light painting**: Write words in the air (mirror image)
- **Outline light painting**: Trace outlines around objects

## FAQ

### Trails not bright enough?
- Increase LED brightness
- Use higher density strip (144/m)
- Slow down your movement

### Background too bright?
- Lower ISO
- Narrow aperture (increase f value)
- Choose a darker environment
