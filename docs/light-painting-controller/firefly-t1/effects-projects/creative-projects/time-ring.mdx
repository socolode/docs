# Time Ring

Attach an LED ring to your Firefly T1 and turn it into a desktop clock — display time, countdown, and pomodoro timer. A practical tool and desktop decoration in one.

## What You Need

- Firefly T1 main unit
- WS2812 LED ring (16-24 LEDs recommended)
- Base or stand (optional)

## Preparation

1. Follow the <Link to="../compatible-leds-wiring">wiring guide</Link> to connect the LED ring
2. Install the time ring effect file
3. Place the ring on your desk

## Usage

### Clock Mode

LEDs light up at time positions to show the current time. Different colors represent hour, minute, and second hands.

### Countdown Mode

Set a countdown time, and the ring gradually turns off to show remaining time.

### Pomodoro Mode

25-minute work + 5-minute break cycle. Ring color changes to indicate the current phase.

## Creative Ideas

- Pair with a <Link to="../3d-printing">3D printed enclosure</Link> for a custom base
- Combine multiple rings for richer information display
