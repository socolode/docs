# Compatible LEDs & Wiring Guide

## Supported Types

### WS2812 / NeoPixel Strips

The most common smart LED strips, each LED independently controllable. Ideal for light painting, ambient lighting, and more.

| Spec | Recommended |
|------|-------------|
| Voltage | 5V |
| Density | 30/m, 60/m, 144/m |
| Length | Max 5m recommended (depending on power) |

### WS2812 Rings

Circular LED rings, great for clocks, rhythm lights, and desktop decoration.

| Size | Use Case |
|------|----------|
| 12 LEDs | Small ambient light |
| 16 LEDs | Clock display |
| 24 LEDs | Rich time display |
| 60 LEDs | High-resolution clock |

### Other Compatible LEDs

- SK6812 (RGBW, independent white channel)
- Other WS2812-protocol strips and rings

## 5P-PIN Interface

The Firefly T1 expansion port is a 5P-PIN connector. With the display facing you, pins are numbered left to right.

| Pin | Signal | Description |
|-----|--------|-------------|
| 1 (left) | 5V | Power positive |
| 2 | TX | Serial data out |
| 3 | RX | Serial data in |
| 4 | GPIO | General purpose I/O |
| 5 (right) | GND | Ground |

## Wiring Steps

### Standard Wiring

The Firefly T1 comes with a 5P adapter cable for direct connection to LED strips.

| Firefly T1 | LED Strip/Ring |
|-----------|----------------|
| 5V | 5V / VCC |
| TX | DIN / DI |
| GND | GND |

### Steps

1. Make sure Firefly T1 is powered off
2. Plug the 5P adapter cable into the expansion port
3. Connect the other end to the LED strip/ring
4. Check connections, then power on

## Shopping Guide

- **Light painting**: 144/m high-density strips for smoother light trails
- **Desktop clock**: 16-24 LED rings for clear display
- **Rhythm light**: 24+ LED rings for richer frequency response
- **Ambient wall**: 30/m strips for balanced effects and power

## Safety Tips

- Ensure all LEDs are rated for 5V
- Allow heat dissipation for high-density strips during extended use
- Always power off before wiring
- Avoid hot-plugging the expansion port
- Use external power for high-power LED setups
