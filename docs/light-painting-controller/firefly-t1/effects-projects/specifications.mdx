# Specifications

## Electrical Characteristics

| Parameter | Min | Typical | Max | Unit |
|-----------|-----|---------|-----|------|
| Input Voltage | 4.5 | 5.0 | 5.5 | V |
| Input Current | 0.5 | 1.0 | 2.0 | A |
| Output Voltage | 4.75 | 5.0 | 5.25 | V |
| Output Current | - | 1.5 | 2.5 | A |
| Power Interface | - | Type-C USB | - | - |
| Power Source | Built-in 18650 Li-ion / USB | | | |

## Pin Mapping

| Pin | Function | Description |
|-----|----------|-------------|
| 1 | 5V | Power output |
| 2 | GND | Ground |
| 3 | TX | Serial transmit |
| 4 | RX | Serial receive |
| 5 | GPIO | General purpose I/O |

## 5P-PIN Interface

With the display facing you, pins are numbered left to right.

| Pin | Signal | Description |
|-----|--------|-------------|
| 1 (left) | 5V | Power positive |
| 2 | TX | Serial data out |
| 3 | RX | Serial data in |
| 4 | GPIO | General purpose I/O |
| 5 (right) | GND | Ground |
