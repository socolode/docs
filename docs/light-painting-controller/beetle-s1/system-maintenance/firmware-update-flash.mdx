# Firmware Update & System Flash

## Checking Firmware Version

After powering on, the current firmware version is displayed on the home screen. If you encounter issues or want to try new features, consider updating the firmware.

## Firmware Download

The latest firmware files are available at:

[Beetle S1 Firmware - Baidu Netdisk](https://pan.baidu.com/s/19I89DSC0XkglKS-24e6vkA?pwd=j99s)

## Update Steps

### Via Thonny

1. Install Thonny
2. Download the firmware
3. Flashing steps:
   - Power off the device, hold the "right direction button"
   - Connect to computer via USB data cable (data port)
   - Open Thonny interpreter configuration
   - Click "Install/Update MicroPython"
   - Select the firmware file and COM port

:::caution
If the Beetle S1's COM port doesn't appear, you may not have held the button while connecting to USB.
:::

## Update Tips

- Ensure the device has sufficient battery before updating
- Unless you have specific needs, use the latest stable firmware
- If issues arise after updating, you can flash back to a previous version
