# Creative Tutorials

The Beetle S1's integrated handle design and high power output enable a wide range of creative projects.

## Light Painting Photography

The S1's core use case. Use the light painting wand kit to create stunning light trails in the dark.

See the <Link to="./light-painting-wand">Light Painting Wand Kit</Link> section for detailed instructions.

## Handheld Ambient Light

The S1's handle shape is comfortable to hold, making it a great portable ambient light.

- Perfect for parties, music festivals, camping
- Choose colorful gradient or rhythm light effects
- Wave it in your hand to create atmosphere

## Desktop Light Installations

Connect an LED ring or strip via the XT30 port for desktop decoration.

- **Desktop Clock**: Use an LED ring to display time
- **Rhythm Light**: Connect an external microphone module (via 4PIN port) for sound-reactive lighting
- **Ambient Light**: Choose gradient or breathing effects

## Large Light Installations

The S1's high power output can drive longer LED strips, ideal for:

- Event lighting
- Outdoor art installations
- Party decoration

## More Ideas

- **Prop Lighting**: Mount the S1 on props for cosplay or performance lighting
- **Interactive Installations**: Connect external sensors via the 4PIN port for interactive light art
- **Multi-device Sync**: Use multiple S1s simultaneously for richer lighting scenes
