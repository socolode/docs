# Specifications

## Electrical Characteristics

| Parameter | Min | Typical | Max | Unit |
|-----------|-----|---------|-----|------|
| Input Voltage | 4.5 | 5.0 | 5.5 | V |
| Input Current (Charge Port) | 0.5 | 2.0 | 3.0 | A |
| Output Voltage (XT30) | 4.75 | 5.0 | 5.25 | V |
| Output Current (XT30) | - | 3.0 | 5.0 | A |
| Charge Port | - | Type-C USB | - | - |
| Data Port | - | Type-C USB | - | - |
| Power Source | Built-in Lithium Battery / USB Power | | | |

## Interface Definitions

### XT30(2+2) Main Output

| Terminal | Signal | Description |
|----------|--------|-------------|
| High Current + | 5V | Power positive (high current) |
| High Current - | GND | Power ground |
| Signal + | DATA | Control signal |
| Signal - | GND | Signal ground |

### XH2.54-4P Expansion Port

| Pin | Signal | Description |
|-----|--------|-------------|
| 1 | 3.3V | Power output |
| 2 | SDA / MOSI | I2C data / SPI master-out-slave-in |
| 3 | SCL / SCK | I2C clock / SPI clock |
| 4 | GND | Ground |

| Parameter | Value |
