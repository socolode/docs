# Light Painting Wand Kit

The Beetle S1's core use case is the light painting wand. With the official light painting wand kit, the handle transforms into a professional light painting wand for creating stunning light trails.

## Kit Contents

| Item | Description |
|------|-------------|
| Beetle S1 Host | Handle-shaped light controller |
| Light Painting Wand LED Strip | High-density strip optimized for light painting |
| XT30 Adapter Cable | Connects host to LED strip |
| Mounting Bracket | Secures the LED strip to the handle |

## Assembly Steps

1. Attach the LED strip to the front of the S1 handle using the mounting bracket
2. Connect the host to the LED strip using the XT30 adapter cable
3. Verify connections and power on
4. Select a light painting effect and start creating

## Light Painting Tips

### Basic Light Painting

Use the S1 light painting wand as a brush, waving it in front of the camera. During the shutter exposure, the LED strip's path will be recorded in the photo.

### Creative Light Painting

- **Multi-color Trails**: Use effects with color gradients for dynamic color changes
- **Text Light Painting**: Write text in the air (remember it will be mirrored)
- **Outline Light Painting**: Trace the outline of objects
- **Multi-person Light Painting**: Use multiple S1s simultaneously for richer compositions

### Camera Settings

| Parameter | Recommended Value |
|-----------|-------------------|
| Mode | Manual (M) |
| Shutter Speed | 2-30 seconds |
| ISO | 100-400 |
| Aperture | f/8-f/11 |
| Focus | Manual focus, pre-focus on the shooting area |
