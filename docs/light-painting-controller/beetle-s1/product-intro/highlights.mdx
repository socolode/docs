# Features & Highlights

## Integrated Handle Design

No base needed - ready to use out of the box. Ergonomic handle shape for comfortable grip during long light painting sessions.

- Integrated body, no assembly required
- Ergonomic handle, comfortable to hold
- Handheld operation, no cable束缚

## High Power Output

Equipped with XT30(2+2) connector supporting high current output, easily driving high-density LED strips and large light installations.

- High current drive, supports longer LED strips
- Keyed XT30 connector for safe wiring
- Ideal for professional light painting and large installations

## Dual Type-C Ports

One fast charging port and one data port - charging and data transfer without interference.

- Charge port: red LED when charging, off when full
- Data port: USB drive mode for file transfer and effect installation
- Charge and transfer data simultaneously

## 4PIN Expansion Interface

XH2.54-4P multi-function expansion port supporting SPI/I2C/UART/GPIO protocols for connecting various sensors and peripherals.

- Connect external microphone for sound-reactive effects
- Connect IMU module for gesture interaction
- Connect sensors for interactive light installations

## Round Color Screen + Physical Buttons

Round color display with function keys, left/right keys, center key, and down key for intuitive operation.

- Round color screen, effect icons at a glance
- Physical buttons for blind operation
- Simple logic, easy to learn

## Open-Source Programmable

Built on MicroPython ecosystem. If you know Python, you can write your own light effects. Easy to get started with rich community resources.

- Complete custom API
- MicroPython standard library support
- Open-source firmware, continuously updated

## Auto Power Off

Automatically powers off after 5 minutes of inactivity. No need to worry about forgetting to turn it off.
