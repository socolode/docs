# What is this?

The Beetle S1 is a handle-shaped professional handheld light controller. Connect an LED strip and it becomes a light painting wand; attach an LED ring and it becomes a desktop ambient light. Drag a file in to switch effects, tweak a few numbers to change colors and speed. If you know Python, you can even write your own effects.

Handle-shaped, integrated design - pick it up and use it. No base, no enclosure, no assembly required.
