# Beetle S1 Product Introduction

## What Is the Beetle S1?

The Beetle S1 is a handle-shaped professional light controller — a more professional version of the Firefly T1. It's more than just a light painting wand: paired with the XT30 high-power interface, it can drive a wide range of light fixtures, handling everything from light painting and light installations to ambient lighting.

It uses the Python language to control lights — as simple as dragging files onto a USB drive, with no complex environment to install. Just use AI to generate the Python script you want and drag it in to control the lights. Through the 4PIN expansion interface, you can connect a wide range of expansion accessories and sensors to develop more ways to play. A special snail-gimbal structure lets you attach various light fixtures and accessories while freely adjusting angles and mounting. More rich expansion accessories are in active development — stay tuned.

## Who Is It For?

The Beetle S1 is for anyone who loves working with lights and wants to create unique effects — from beginners to advanced creators, everyone can find their way to play:

- **Light painting enthusiasts**: Capture professional light-trail photos without getting tangled in complex gear
- **Lighting makers & DIYers**: Write your own light programs in Python and build one-of-a-kind installations
- **Content creators**: Streaming, set design, and ambiance — a flexible yet professional light controller
- **Complete beginners**: Ready out of the box with simple programming — a stress-free first step into working with lights

## Key Features

### High Power Output

- XT30(2+2) high-power interface with high current drive, easily powering longer and more LED strips
- Keyed XT30 connector for safe, reliable wiring
- Handles light painting, ambient lighting, large light installations, and more

### Simple Programming

- Uses the Python language — friendly for everyone, no programming background needed
- As simple as dragging files onto a USB drive — use AI to generate a Python script and drag it in to control the lights
- No complex environment to install — plug and play, ready out of the box

<img src={require('../assets/beetle-s1-programming.png').default} alt="Beetle S1 Python Programming" style={{ borderRadius: '16px', maxWidth: '100%', display: 'block', margin: '24px auto' }} />

### Flexible Expansion

- 4PIN expansion interface supporting SPI/I2C/UART/GPIO protocols
- Connect microphones, IMU, and other sensors to unlock sound-reactive and gesture-controlled interactions

### Snail-Gimbal Structure

- Attach various light fixtures and accessories while freely adjusting angles and mounting

### Dual Type-C Ports

- One fast charging port and one data port — charging and data transfer without interference
- Data port USB drive mode for easy file transfer and effect installation

### Color Screen + Buttons

- Color screen: effect icons and current status are clear at a glance
- Distinctive 5-way button plus a custom button: smooth select, confirm, and back — clear logic
- Clear button feedback works even by touch

### Auto Power Off

- Automatically powers off after 5 minutes of inactivity
