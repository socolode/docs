# S1 Hardware Programming

This section covers how to write peripheral drivers and adapt external sensors through the 4PIN expansion interface.

## 4PIN Interface Programming Basics

The S1's XH2.54-4P expansion port supports SPI/I2C/UART/GPIO protocols.

### I2C Communication Example

```python
from machine import Pin, I2C

# Initialize I2C
i2c = I2C(0, scl=Pin(3), sda=Pin(2), freq=400000)

# Scan for I2C devices
devices = i2c.scan()
print("I2C devices:", [hex(addr) for addr in devices])
```

### GPIO Control Example

```python
from machine import Pin

# Set GPIO
ext_pin = Pin(2, Pin.OUT)
ext_pin.value(1)  # Output high
```

## External Microphone Module (Sound-Reactive Effects)

Since the S1 has no built-in microphone, connect an external microphone module via the 4PIN port for sound-reactive effects.

### Wiring

| 4PIN Port | Microphone Module |
|-----------|-------------------|
| 3.3V | VCC |
| SDA/MOSI | Analog output |
| GND | GND |

### Example Code

```python
from machine import Pin, ADC
import time

# Initialize ADC
mic = ADC(Pin(2))

while True:
    value = mic.read()
    # Map sound level to brightness
    brightness = value // 4  # 0-255 mapping
    print("Sound level:", brightness)
    time.sleep_ms(100)
```

## External IMU Module (Gesture Interaction)

Connect an MPU6050 or similar IMU module via the 4PIN port.

### Wiring

| 4PIN Port | IMU Module |
|-----------|------------|
| 3.3V | VCC |
| SDA/MOSI | SDA |
| SCL/SCK | SCL |
| GND | GND |

### Example Code

```python
from machine import Pin, I2C
import time

# MPU6050 address
MPU6050_ADDR = 0x68

i2c = I2C(0, scl=Pin(3), sda=Pin(2), freq=400000)

# Wake up MPU6050
i2c.writeto_mem(MPU6050_ADDR, 0x6B, b'\x00')

while True:
    # Read accelerometer data
    data = i2c.readfrom_mem(MPU6050_ADDR, 0x3B, 6)
    ax = (data[0] << 8) | data[1]
    ay = (data[2] << 8) | data[3]
    az = (data[4] << 8) | data[5]
    print("Accel:", ax, ay, az)
    time.sleep_ms(100)
```

## Precautions

- The 4PIN port outputs 3.3V - external modules must support 3.3V power
- Check wiring orientation to avoid shorts
- It's recommended to connect modules while the device is powered off
