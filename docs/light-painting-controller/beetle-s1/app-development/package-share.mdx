# Beetle S1 - Package & Share Light Programs

After writing your light program, you can package it into an effect file for easy sharing with other users.

## Preparation

Before packaging, make sure your light program has been tested and runs correctly on the Beetle S1.

## Creating an Effect Icon

Create a preview icon for your light effect so other users can identify it on the device:

Icon requirements:
- Format: PNG
- Recommended size: 64×64 pixels
- File name: Same as the effect folder name

## Packaging the Effect

Follow the demo effect's directory structure to package your program and icon:

Steps:
1. Create your effect folder under `/apps/`
2. Place your light program file inside
3. Add the effect icon file
4. Update the `config.json` configuration file

## Testing on Device

Upload the packaged effect to your Beetle S1 and test it on the device:

:::caution
Make sure to disable the "Restart interpreter before running code" option in Thonny to avoid device restarts.
:::

## Sharing with the Community

Once packaged, feel free to share your work with the community:

- Compress the effect files into a ZIP package
- Include a description and screenshots
- Share on community forums or social media
