# Custom API

The Beetle S1 runs on MicroPython with a custom API mostly compatible with the Firefly T1. Below is the API reference adapted for the S1.

## Display

### `display_text(text, x, y, color)`

Display text on the screen.

- `text` (str): Text to display
- `x` (int): X coordinate
- `y` (int): Y coordinate
- `color` (int, optional): Color value, default white

### `display_clear()`

Clear the screen.

## Button Input

### `button_was_pressed(button_id)`

Check if a specific button was pressed.

- `button_id` (str): Button identifier: `"up"`, `"down"`, `"left"`, `"right"`, `"center"`, `"function"`

Returns `True` or `False`.

## LED Control

### `set_led(index, r, g, b)`

Set the color of a single LED.

- `index` (int): LED index
- `r` (int): Red value (0-255)
- `g` (int): Green value (0-255)
- `b` (int): Blue value (0-255)

### `set_all_leds(r, g, b)`

Set all LEDs to the same color.
