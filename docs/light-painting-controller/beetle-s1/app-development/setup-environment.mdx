# Beetle S1 - Development Environment Setup

For users with some programming experience who want to write their own light effects.

## Install Thonny

Visit [https://thonny.org/](https://thonny.org/) to download and install Thonny.

Thonny is a lightweight IDE designed for MicroPython, ready to use out of the box with no additional configuration.

## Update Firmware

Make sure your Beetle S1 is running the latest firmware for compatibility with the latest development features.

See the <Link to="../system-maintenance/firmware-update-flash">Firmware Update & Flash</Link> section for firmware update instructions.

## Run Your First Program

Connect your Beetle S1 to your computer (use the data port) and open Thonny:

1. Select the correct COM port in the bottom-right corner of Thonny
2. Enter the following code in the editor:

```python
print("Hello, Beetle S1!")
```

3. Click the run button (green triangle) to see the output in the console

:::tip
If you can't find the COM port, check that your USB cable supports data transfer and that the device is powered on.
:::
