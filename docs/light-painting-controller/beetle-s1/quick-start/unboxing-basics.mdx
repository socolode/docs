# Unboxing & Basic Operations

## What's in the Box

| Item | Description |
|------|-------------|
| Beetle S1 Host | Handle-shaped integrated light controller |
| XT30 Adapter Cable | For connecting LED strips or accessories |
| Type-C Cable (Charging) | Fast charging cable |
| Type-C Cable (Data) | For connecting to computer for file transfer |

## Port Overview

| Port | Description |
|------|-------------|
| XT30(2+2) Connector | Main output, high current + control signal, for LED strips |
| Fast Charge Port (Type-C) | Charging, red LED when charging, off when full |
| Data Port (Type-C) | Connect to computer/phone for debugging and file transfer |
| 4PIN Multi-function Port (XH2.54-4P) | SPI/I2C/UART/GPIO expansion |
| Reset Button | Quick restart in case of issues |

## Charging

Use the included charging Type-C cable to connect to a charger.

- Red LED indicator on the fast charge port when charging, turns off when fully charged
- Use a 5V/2A or higher charger for faster charging
- Can use phone charger or power bank

## Power On & Off

**Power On**
1. With the device powered off
2. Press and hold the "center button" for 2 seconds until the screen lights up

**Power Off**
1. Exit all light effects to return to the "home screen"
2. Press the "down button" once to power off

:::tip
The S1 automatically powers off after 5 minutes of inactivity to save battery.
:::

## Button Guide

| Button | Function |
|--------|----------|
| Function Key | Special functions / menu shortcut |
| Left/Right Keys | Navigate effects / adjust parameters |
| Center Key | Press to enter effect / confirm; hold 2 seconds to exit / power on |
| Down Key | Press to power off / go back |

## Entering & Exiting Light Effects

**Entering an Effect**
1. Press left/right to select the desired effect
2. Press the center button to enter the effect

**Exiting an Effect**
1. While in a light effect
2. Press and hold the center button for 2 seconds to return to the home screen

## Connecting to Computer

Connect the data Type-C cable to your computer. A new USB drive will appear, allowing you to update light effects or transfer files.

:::tip
If no USB drive appears, make sure you're using the data cable (supports data transfer) and not just a charging cable.
:::

## Notes

- The device can be stored directly after powering off - no need to remove the battery
- When plugged in, the device automatically switches to external power mode
- For best charging and data transfer performance, use the included cables
