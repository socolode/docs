# Install Your First Effect

Get your Beetle S1 lighting up in 5 minutes.

## Step 1: Download an Effect

Open the <Link to="../effects-projects/effect-list-install">Effect List & Installation</Link> page, choose a light effect you like and download it.

## Step 2: Connect to Computer

Use the USB data cable (data port) to connect your Beetle S1 to your computer. After a few seconds, a new USB drive will appear.

## Step 3: Drag and Drop

1. Open the USB drive and find the `/apps` folder
2. Drag the downloaded effect file into the `/apps` folder
3. Open `/apps/config.json` with a text editor and add the new effect information following the format

## Step 4: Enjoy the Effect

1. Safely eject the USB drive and disconnect the cable
2. Power on the device
3. Use the left/right buttons to select the new effect
4. Press the center button - lights up!

For detailed installation instructions, see <Link to="../effects-projects/effect-list-install">Effect List & Installation</Link>.
