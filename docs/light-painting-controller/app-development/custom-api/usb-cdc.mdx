# USB Serial Control (CDC)

The Type-C USB port of the Firefly T1 integrates both **MSC (Mass Storage Class)** and **USB-CDC (Communication Device Class)** by default, enabling U-disk storage and serial communication at the same time. When you connect the device to your computer with a data cable, the system automatically recognizes it and creates both a U-disk device and a serial device.

## Introduction

This article focuses on the **USB-CDC** feature, i.e. USB serial communication capability. With this feature, you do not need to install any driver or extra component. Simply connect the Firefly T1 to your computer with a USB data cable and the two can communicate directly — simple and efficient.

![Firefly T1 USB-CDC serial port interface diagram](./assets/usb-cdc-interface.png)

## Use Cases

- **Command control**: Run a "serial assistant" tool on your computer to send data or control commands to the Firefly T1, enabling real-time control of the device.
- **Data transfer**: Data collected by the Firefly T1 can be uploaded directly to the computer via serial communication for further analysis and processing.

## Usage Examples

### 1. Computer Sends Commands to Firefly T1

**API:**

```python
import sys

cmd = sys.stdin.readline().strip()
```

**Explanation:**

- The computer (serial assistant) sends one line of data, and the ESP32-S3 reads it via `sys.stdin.readline()`.
- The read `cmd` is a string with the newline character removed.

**Example:**

```python
import sys

while True:
    cmd = sys.stdin.readline().strip()
    print("Received command:", cmd)
```

### 2. Firefly T1 Uploads Data to Computer

**API:**

```python
import sys

sys.stdout.write("data content\n")
# or more simply
print("data content")
```

**Explanation:**

- The ESP32-S3 sends data to the computer via `sys.stdout.write()` or `print()`.
- The computer's serial assistant will receive this data.

**Example:**

```python
import sys
import time

for i in range(5):
    sys.stdout.write("upload data: {}\n".format(i))
    time.sleep(1)
```
