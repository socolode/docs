# Firefly T1 - Setup Development Environment

Suitable for users with some programming experience who want to create their own light effect scripts.

## Install Thonny IDE

Go to [https://thonny.org/](https://thonny.org/) to download and install Thonny.

Thonny is a lightweight IDE designed for MicroPython, ready to use out of the box with no additional configuration needed.

## Update Firefly T1 Firmware

Make sure your Firefly T1 is running the latest firmware for compatibility with the latest development features.

Refer to the <Link to="../system-maintenance/firmware-update-flash">Firmware Update & Flash</Link> section to update the firmware.

## Run Your First Program

Connect Firefly T1 to your computer, open Thonny:

1. Select the corresponding COM port in the bottom-right corner of Thonny
2. Enter the following code in the editor:

```python
print("Hello, Firefly T1!")
```

3. Click the Run button (green triangle) to see the output in the console

:::tip
If you can't find the COM port, check that your USB cable supports data transfer and the device is powered on.
:::
