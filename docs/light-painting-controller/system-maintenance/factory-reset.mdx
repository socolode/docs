# Factory Reset

A factory reset clears all installed light apps and user configurations, restoring the system to its original state. Use this when:

- The system is behaving abnormally and you can't fix it
- Your app files are messy and you want a fresh start
- You're selling or transferring the device and need to clear personal data

## Method 1: Clear the USB Drive and Re-download System Files

If the system boots normally, you can restore it by clearing the USB drive and re-downloading the system files:

1. Connect the device to your computer and enter USB mode
2. Clear all files on the USB drive
3. Go to [firefly-t1/apps](https://github.com/socolode/firefly-t1/tree/main/apps) and download the required system files, then copy them back to the device

:::caution
Factory reset will **delete all installed light apps**. Back up the `/apps/` folder first if needed.
:::

## Method 2: Reset by Re-flashing Firmware

If the system won't boot or the USB clearing method is unavailable, re-flash the firmware to restore the system:

1. Follow the steps in <Link to="./firmware-update-flash">Firmware Update & Flash</Link>
2. Download the latest firmware and flash it to the device
3. After flashing, the device will be restored to factory state

## After Reset

Once the factory reset is complete, the device will be in its out-of-box state:

1. Boots into the welcome screen
2. Built-in default apps are still present
3. You'll need to re-install any additional apps (see <Link to="../firefly-t1/quick-start/first-app">Install Your First App</Link>)

## Backup Tips

Before resetting, we recommend backing up:

- Connect the device to your computer via USB
- Copy the entire `/apps/` folder to your computer
- After reset, drag the backup back into the USB drive
