# 产品介绍
欢迎使用 **Socolode** 文档。这里是搭建、定制和运营 Socolode 店铺所需的全部资料。
## Socolode 是什么
Socolode 是一个电商平台，帮助你创建和管理独立站。它涵盖商品目录、结账、支付、物流和店铺装修，让你专注于业务增长。
## 文档面向谁

- **店主**：首次搭建独立站
- **开发者**：对接 Socolode API 或定制主题
- **运营团队**：管理订单、支付和履约
