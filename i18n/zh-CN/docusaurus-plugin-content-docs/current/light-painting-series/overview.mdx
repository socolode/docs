# 光绘系列

欢迎来到烁彩代码光绘系列 —— 这是一系列为摄影师、创作者和爱好者设计的模块化、易用光绘工具。

## 什么是光绘？

光绘是一种通过在长时间曝光期间移动光源来创建图像的摄影技术。使用烁彩代码的光绘棒，你可以：

- **用光作画** — 在长曝光照片中创建文字、图案和艺术效果
- **拍摄人像** — 为人像摄影添加创意光轨和光效
- **自定义图案** — 上传你自己的图片、文字或 Logo，实现独一无二的光绘
- **探索创意** — 无需绘画基础，只需挥动光绘棒，就能创作出精彩作品

入门级模块化光绘棒 —— 非常适合新手和专业摄影师使用。
