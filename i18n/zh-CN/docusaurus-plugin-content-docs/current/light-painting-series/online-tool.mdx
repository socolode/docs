## 使用说明

1. 点击上方 **「打开在线工具」** 按钮，跳转到工具页面
2. 上传你想要处理的图片（支持 JPG、PNG 等格式）
3. 根据你的灯棒规格选择输出像素（144 / 192 / 240 / 288 / 480 等）
4. 调整横竖刷方向、自然饱和度、黑白调节等参数
5. 点击下载按钮，会得到一个包含 BMP + JPG 的 ZIP 压缩包
6. 将生成的 BMP 文件重命名为数字或英文，放到光绘棒 `/sd/image` 目录即可使用

:::tip 隐私安全
所有图片均在您的本地浏览器中处理，不会上传到任何服务器，可放心使用！
:::
