## 常见问题

### OpenStick T1 和 S1 有什么区别？

T1 和 S1 是不同型号的光绘棒，具体差异请参考各自的产品文档。文档正在陆续更新中。

### 光绘棒支持哪些图片格式？

光绘棒通常支持 BMP 格式的素材文件，可通过[在线工具](../light-painting-series/online-tool)将普通图片转换为 BMP 格式。

### 如何将素材上传到光绘棒？

通过 USB 连接光绘棒到电脑，将 BMP 文件复制到 SD 卡或内部存储的 image 目录即可。

### 光绘棒可以自己编程吗？

OpenStick 系列支持二次开发，可通过 Arduino IDE 或其他工具自行编写固件和效果。

### 配件是否兼容不同型号的光绘棒？

部分配件通用，部分为特定型号专用，请参考配件文档中的兼容性说明。
