# 店铺配置

上线前完成店铺基础设置。

## 店铺资料

进入**设置 > 店铺资料**设置店铺身份信息。

### 基本信息

- **店铺名称**：显示在导航栏、页脚和浏览器标签
- **Logo**：上传 PNG 或 SVG，建议尺寸 200x200px
- **Favicon**：32x32px 浏览器标签图标
- **店铺描述**：160 字以内，用于搜索结果和社交分享

### 联系方式

设置客户在订单确认邮件和联系页面看到的邮箱与电话。平台发出的交易邮件也会使用这些信息。

## 货币与税务

在**设置 > 货币**中选择默认店铺货币。Socolode 支持面向国际客户的多币种展示。

税务设置在**设置 > 税务**中配置：

- 根据客户位置自动计算税费
- 为特定地区设置手动税率
- 含税定价与不含税定价

## 运费区域

在**设置 > 物流**中定义配送范围和费用。

1. 创建运费区域（如"国内"或"国际"）
2. 向区域添加国家或地区
3. 设置运费：固定费率、按重量计费、或满额包邮

## 员工账号

在**设置 > 员工**中邀请团队成员。每个账号分配角色：

- **管理员**：拥有所有设置和数据的完整权限
- **员工**：可管理商品和订单，不能修改账单
- **开发者**：仅可访问 API 密钥和主题代码

## 通知偏好

在**设置 > 通知**中选择哪些事件触发邮件或站内提醒：

- 收到新订单
- 库存不足预警（按商品设置阈值）
- 客户注册
- 支付失败
