# 店铺设置
上线前配置你的店铺设置。
## 店铺资料
进入**设置 > 店铺资料**设置你的店铺身份信息。
### 基本信息

- **店铺名称**：显示在导航栏、页脚和浏览器标签页
- **Logo**：上传 PNG 或 SVG 格式，建议尺寸 200x200px
- **网站图标（Favicon）**：32x32px 图标，显示在浏览器标签页
- **店铺描述**：160 字以内的摘要，用于搜索结果和社交分享

### 联系方式

设置客户在订单确认页和联系页面看到的邮箱和电话号码。这些信息也会显示在平台发送的事务性邮件中。

## 货币与税务

在**设置 > 货币**中，选择你的店铺默认货币。Socolode 支持为国际客户显示多货币。

关于税务，进入**设置 > 税务**进行配置：

- 根据客户位置自动计算税费
- 特定地区的手动税率
- 含税价与不含税价设置

## 配送区域

在**设置 > 配送**中定义你的配送范围和运费。

1. 创建配送区域（例如"国内"或"国际"）
2. 向区域中添加国家或地区
3. 设置运费：固定运费、按重量计费或满额包邮

## 员工账号

在**设置 > 员工**中邀请团队成员。每个员工账号对应一个角色：

- **管理员**：拥有所有设置和数据的完全访问权限
- **员工**：可以管理商品和订单，不能修改账单设置
- **开发者**：仅可访问 API 密钥和主题代码

## 通知偏好

在**设置 > 通知**中，选择哪些事件会触发邮件或站内提醒：

- 收到新订单
- 库存不足警告（可为每个商品设置阈值）
- 客户注册
- 支付失败
