# 萤火虫T1 开发环境搭建

适合有一定编程基础的用户，想自己编写灯光效果程序。

## 安装 Thonny 编程工具

前往 [https://thonny.org/](https://thonny.org/) 下载并安装 Thonny。

Thonny 是一款专为 MicroPython 设计的轻量级 IDE，开箱即用，无需额外配置。

## 更新萤火虫 T1 固件

确保你的萤火虫T1 运行的是最新固件，以兼容最新的开发特性。

参考<Link to="../system-maintenance/firmware-update-flash">固件更新与烧录</Link>章节更新固件。

## 运行第一个程序

连接萤火虫T1 到电脑，打开 Thonny：

1. 在 Thonny 右下角选择对应的 COM 端口
2. 在编辑器中输入以下代码：

```python
print("Hello, Firefly T1!")
```

3. 点击运行按钮（绿色三角），即可在控制台看到输出

:::tip
如果找不到 COM 端口，请检查数据线是否支持数据传输，以及设备是否已开机。
:::
