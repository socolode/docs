# 规格参数

## 电子电气特性

| 参数 | 最小值 | 典型值 | 最大值 | 单位 |
|------|--------|--------|--------|------|
| 输入电压 | 4.5 | 5.0 | 5.5 | V |
| 输入电流 | 0.5 | 1.0 | 2.0 | A |
| 输出电压 | 4.75 | 5.0 | 5.25 | V |
| 输出电流 | - | 1.5 | 2.5 | A |
| 电源接口 | - | Type-C USB | - | - |
| 电源类型 | 内置18650锂电池 / USB供电 | | | |

## 管脚映射

| 管脚编号 | 功能 | 说明 |
|---------|------|------|
| 1 | 5V | 电源输出 |
| 2 | GND | 地线 |
| 3 | TX | 串口发送 |
| 4 | RX | 串口接收 |
| 5 | GPIO | 通用IO |

## 5P-PIN接口映射

注意：显示屏面为"正面"，5P-PIN的顺序为正面"从左往右"。

| 引脚顺序 | 信号 | 说明 |
|---------|------|------|
| 1 (左) | 5V | 电源正极 |
| 2 | TX | 串口数据发送 |
| 3 | RX | 串口数据接收 |
| 4 | GPIO | 通用输入输出 |
| 5 (右) | GND | 电源地 |
