# 兼容灯材与接线指南

## 支持的类型

### WS2812 / NeoPixel 灯带

最常见的智能灯带，每颗LED可独立控制颜色和亮度。适合光绘、氛围灯等场景。

| 规格 | 推荐 |
|------|------|
| 电压 | 5V |
| 密度 | 30灯/米、60灯/米、144灯/米 |
| 长度 | 建议不超过5米（视功率需求） |

### WS2812 灯环

圆形灯环，适合做时钟、节奏灯、桌面装饰。

| 规格 | 适用场景 |
|------|----------|
| 12灯 | 小型氛围灯 |
| 16灯 | 时钟显示 |
| 24灯 | 丰富的时间显示效果 |
| 60灯 | 高分辨率时钟 |

### 其他兼容灯材

- SK6812 (RGBW，支持独立白色通道)
- 其他基于 WS2812 协议的灯带/灯环

## 5P-PIN 接口定义

萤火虫T1 的扩展接口为 5P-PIN 座，显示屏面为"正面"，引脚顺序为正面"从左往右"。

| 引脚顺序 | 信号 | 说明 |
|---------|------|------|
| 1 (左) | 5V | 电源正极 |
| 2 | TX | 串口数据发送 |
| 3 | RX | 串口数据接收 |
| 4 | GPIO | 通用输入输出 |
| 5 (右) | GND | 电源地 |

## 接线步骤

### 标准接线

萤火虫T1 的 5P 接口标配了一根转接线，直接连接灯带即可。

| 萤火虫T1 | 灯带/灯环 |
|----------|-----------|
| 5V | 5V / VCC |
| TX | DIN / DI |
| GND | GND |

### 接线步骤

1. 确认萤火虫T1 已关机
2. 将 5P 转接线插入萤火虫T1 的扩展接口
3. 将转接线的另一端连接到灯带/灯环的对应接口
4. 检查接线无误后开机

## 选购建议

- **光绘**：推荐 144灯/米 的高密度灯带，光轨更细腻
- **桌面时钟**：推荐 16-24灯 灯环，显示效果清晰
- **节奏灯**：推荐 24灯 以上灯环，频率响应更丰富
- **氛围灯墙**：推荐 30灯/米 灯带，平衡效果和功耗

## 注意事项

- 请确保灯材工作电压为 5V
- 长时间使用高密度灯带时，注意散热
- 接线前请确保设备已关机
- 避免在通电状态下插拔接口
- 大功率灯材建议使用外接电源
