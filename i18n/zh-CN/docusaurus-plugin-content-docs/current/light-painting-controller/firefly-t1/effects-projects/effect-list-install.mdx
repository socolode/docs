# 效果一览与安装

## 效果一览

效果库是一个在线表格，提供各种萤火虫T1可用的灯光效果下载。请访问 [萤火虫T1 效果库](https://socolode.yuque.com/ogwgwg/xnlyru/ktn7g8bbx5d6wln6) 查看完整的效果列表和下载链接。

## 安装灯光效果

### 1. 下载效果文件

打开效果库，选择一个喜欢的灯光效果并下载。

### 2. 连接电脑

用 USB 数据线将萤火虫T1 连接到电脑。等待几秒钟，电脑上会出现一个新的 U 盘。

### 3. 添加效果

1. 把下载回来的灯光效果文件，直接放入U盘的 `/apps` 文件夹里面

![效果文件](../assets/firefly-t1-09.png)

### 4. 注册效果（启用效果）

1. 用电脑的文本编辑工具，打开U盘里面的 `apps/config.json` 文件

![config.json](../assets/firefly-t1-10.png)

2. 在 `config.json` 文件里面，添加新的效果信息

![配置示例](../assets/firefly-t1-11.png)

**添加说明：**

如图，就是1个灯光效果的基本信息，需要把"新添加"的效果的基本信息按照如下格式，填进配置文件里面。

- `"name"`: 效果名称
- `"folder"`: 效果文件夹路径
- `"enabled"`: 是否启用效果

:::note 注意
- 必须填写 `config.json` 文件，才能显示效果图标以及使用效果
- 元素列表的顺序，就是效果的显示顺序
:::

### 5. 启动效果

如添加和配置成功之后，萤火虫开机，左右拨动摇杆，即可显示出新添加的效果，单击"中键"即可启动新的效果！
