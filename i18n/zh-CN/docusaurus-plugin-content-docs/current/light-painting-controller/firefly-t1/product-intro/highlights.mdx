# 产品特点与卖点

## 轻巧便携

掌心大小，装进口袋。无论户外光绘、桌搭氛围，还是派对布景，随时都能掏出来用。

- 内置 18650 锂电池供电，摆脱线缆束缚
- Type-C 充电，与手机共用充电线
- 整机重量仅约 XX 克

## 即插即用

无需焊接、无需编程基础。装上电池就能用，插上电脑就能传文件，5 分钟就能体验第一个灯光效果。

- U 盘模式拖拽安装效果文件
- 五向按键快速切换效果
- 支持灯带、灯环等多种配件

## 开源可编程

懂 Python 就能自己写灯光效果。基于 MicroPython 生态，开发上手简单，社区资源丰富。

- 完整的自定义 API
- MicroPython 标准库支持
- 开源固件，持续更新

## 创意无限

从光绘摄影到桌面时钟，从节奏灯到互动装置——萤火虫T1 的玩法由你的想象力决定。

- 兼容市面上常见的 WS2812 灯带/灯环
- 支持 3D 打印外壳，打造个性化外观
- 社区持续分享新玩法、新效果
