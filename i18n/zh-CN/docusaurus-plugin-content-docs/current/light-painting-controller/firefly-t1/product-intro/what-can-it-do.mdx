# 它能做什么？

## 光绘摄影

接上灯带，萤火虫T1 就变成一支光绘笔。在夜空中挥舞，相机长曝光就能拍出炫酷的光轨照片。适合创意摄影、产品拍摄、活动现场。

**你需要：** 萤火虫T1 + 灯带 + 三脚架 + 支持长曝光的相机/手机

详细教程请参考<Link to="../effects-projects/creative-projects/light-painting">光绘摄影指南</Link>。

## 时光环

套上灯环，萤火虫T1 变身桌面时钟。显示时间、倒计时、番茄钟——既是实用工具，也是桌面装饰。

**你需要：** 萤火虫T1 + 灯环

详细教程请参考<Link to="../effects-projects/creative-projects/time-ring">时光环制作指南</Link>。

## 桌面节奏灯

灯环随音乐律动，根据音频频率响应变换色彩和亮度。放在桌面上，它就是最抢眼的氛围灯。

**你需要：** 萤火虫T1 + 灯环 + 音频源

详细教程请参考<Link to="../effects-projects/creative-projects/rhythm-light">桌面节奏灯制作指南</Link>。

## 氛围灯墙

多组灯带拼接，营造沉浸式灯光环境。可自定义颜色渐变、呼吸效果，适合直播间、工作室、派对场景。

**你需要：** 萤火虫T1 + 多组灯带

## 更多可能…

这只是开始。结合 3D 打印外壳和传感器，你还可以做出互动灯光装置、智能感应灯、创意装饰……萤火虫T1 的玩法由你的想象力决定。
