# 这是什么？

萤火虫T1 是一个掌心大小的灯光控制主机。接上灯带，它就是光绘棒；套上灯环，它就是桌面时钟和节奏灯。拖一个文件进去就能切换灯光效果，想改颜色和速度？调几个数字就行。懂 Python 的话，还能自己写效果。

这不是一块需要焊接的开发板——装上电池就能用，插上电脑就能传文件，整个过程不需要任何编程基础。
