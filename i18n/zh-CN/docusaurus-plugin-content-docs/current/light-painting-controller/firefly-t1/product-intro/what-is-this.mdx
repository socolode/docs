# 萤火虫T1 产品介绍

## 这是什么？

萤火虫T1 是一款介于传统开发板和成品之间的产品，既可作为独立运行的设备，又可以通过搭配各种附件实现多样化的功能，专为创意灯光场景设计。装上电池就能用，插上电脑就能传文件。拖个文件进去切换效果，改几个数字调整参数——零基础也能上手。懂编程的话，写个脚本就能实现任意灯光控制。

## 光绘摄影

接上灯棒，配合相机长曝光，萤火虫T1 就能拍出炫酷的光轨照片。详细教程请参考<Link to="../effects-projects/creative-projects/light-painting">光绘摄影指南</Link>。

## 更多创意玩法

### 时光环

套上灯环，萤火虫T1 变身桌面时钟。显示时间、倒计时、番茄钟——既是实用工具，也是桌面装饰。

**你需要：** 萤火虫T1 + 灯环

详细教程请参考<Link to="../effects-projects/creative-projects/time-ring">时光环制作指南</Link>。

### 桌面节奏灯

灯环随音乐律动，根据音频频率响应变换色彩和亮度。放在桌面上，它就是最抢眼的氛围灯。

**你需要：** 萤火虫T1 + 灯环 + 音频源

详细教程请参考<Link to="../effects-projects/creative-projects/rhythm-light">桌面节奏灯制作指南</Link>。

### 氛围灯墙

多组灯带拼接，营造沉浸式灯光环境。可自定义颜色渐变、呼吸效果，适合直播间、工作室、派对场景。

**你需要：** 萤火虫T1 + 多组灯带

## 产品亮点

### 轻巧便携

- 内置 18650 锂电池供电，摆脱线缆束缚
- Type-C 充电，与手机共用充电线
- 整机仅比一节 18650 电池重一点

### 即插即用

- U 盘模式拖拽安装效果文件
- 五向按键快速切换效果
- 支持灯带、灯环等多种配件

### 开源可编程

- 完整的自定义 API
- 基于 MicroPython，社区资源丰富
- 开源固件，持续更新

### 创意无限

- 兼容市面上常见的 WS2812 灯带/灯环
- 支持 3D 打印外壳，个性化外观
- 社区持续分享新玩法、新效果
