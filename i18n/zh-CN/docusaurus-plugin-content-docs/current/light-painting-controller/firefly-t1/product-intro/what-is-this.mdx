# 萤火虫T1 产品介绍

## 萤火虫T1是什么？

萤火虫T1 是一款专门为了玩转炫彩 LED 灯而设计的便携式可编程灯光控制器。内置多种主流传感器，可更换 18650 电池，拓展接口丰富。配合 AI 编程，无论是摄影爱好者还是电子发烧友，都能轻松上手，轻易实现各种你需要的灯光效果。

## 为什么要用这款设备？

你可能见过别人拍出炫酷的光绘照片、把桌面灯光玩出各种花样，却总觉得"那是会玩的人才能做到的事"。萤火虫T1 想解决的，正是"想玩又怕麻烦"这个痛点——它把复杂的灯光创作，变成了打开就能玩的事。

- **想随手记录创意**：不用研究硬件，装上电池、接上灯棒，配合相机就能拍出独特的光绘作品
- **一台设备应对多种场合**：拍照、桌面氛围、派对、直播，同一台设备都能切换出合适的效果
- **想做出独一无二的效果**：不满足于千篇一律的装饰灯，可以按自己的喜好定制，做出别人没有的花样
- **只会越玩越有得玩**：先玩现成的效果上手，熟悉之后还能继续深入，玩法从不设上限

## 更多创意玩法

### 时光环

套上灯环，萤火虫T1 变身桌面时钟。显示时间、倒计时、番茄钟——既是实用工具，也是桌面装饰。

**你需要：** 萤火虫T1 + 灯环

详细教程请参考<Link to="../apps-play/creative-projects/time-ring">时光环制作指南</Link>。

### 桌面节奏灯

灯环随音乐律动，根据音频频率响应变换色彩和亮度。放在桌面上，它就是最抢眼的氛围灯。

**你需要：** 萤火虫T1 + 灯环 + 音频源

详细教程请参考<Link to="../apps-play/creative-projects/rhythm-light">桌面节奏灯制作指南</Link>。

### 氛围灯墙

多组灯带拼接，营造沉浸式灯光环境。可自定义颜色渐变、呼吸效果，适合直播间、工作室、派对场景。

**你需要：** 萤火虫T1 + 多组灯带

## 产品亮点

### 轻巧便携

- 内置 18650 锂电池供电，摆脱线缆束缚
- Type-C 充电，与手机共用充电线
- 整机仅比一节 18650 电池重一点

### 即插即用

- U 盘模式拖拽安装效果文件
- 五向按键快速切换效果
- 支持灯带、灯环等多种配件

### 开源可编程

- 完整的自定义 API
- 基于 MicroPython，社区资源丰富
- 开源固件，持续更新

### 创意无限

- 兼容市面上常见的 WS2812 灯带/灯环
- 支持 3D 打印外壳，个性化外观
- 社区持续分享新玩法、新效果
