# 安装第一个效果

5 分钟让你的萤火虫T1 亮起来。跟着下面几步，就能装好并运行第一个灯光效果。

## 第一步：下载调色盘 App

前往 app 库，下载「调色盘 app」——这是萤火虫T1 上最常用的灯光效果之一，能让你快速看到彩色的灯光变化。

## 第二步：上传到萤火虫T1

用 USB 数据线把萤火虫T1 连接到电脑，然后把下载好的「调色盘 app」上传到萤火虫T1 里面。

## 第三步：连接灯条

把灯条正确接到萤火虫T1 的接口上。接线方法请参考<Link to="../apps-play/compatible-leds-wiring">兼容灯材与接线</Link>。

## 第四步：体验效果

开机运行，在灯条上欣赏「调色盘 app」的彩色灯光效果。

## 第五步：学习自定义效果

想要自己定义灯光效果？前往<Link to="../../app-development/first-script">编写第一个灯光程序</Link>，学习从零开始打造专属效果。
