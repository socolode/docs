# 开箱与基本操作

## 开箱清单

打开包装后，你应该看到以下物品：

| 物品 | 说明 |
|------|------|
| 萤火虫T1 主机 | 内置屏幕和五向按键的灯光控制器 |
| 5P 接口线 | 用于连接灯带或灯环 |
| Type-C 数据线 | 充电和连接电脑 |

:::note
萤火虫T1 不含 18650 电池，请自行准备。
:::

## 安装电池

1. 打开主机背面的电池仓盖
2. 装入 18650 锂电池，注意正负极方向

:::caution 注意
18650电池安装时，注意正负极方向，装反开不了机。
:::

## 充电

使用附带的 Type-C 数据线连接充电器或电脑，即可充电。

- 充电时 Type-C 接口旁有指示灯
- 使用 5V/1A 以上充电器，约 2-3 小时可充满
- 可使用手机充电器或充电宝进行充电

## 开机 & 关机

**开机**
1. 关机的状态下
2. 长按"五向按键"的"中键"2秒后，即可开机

**关机**
1. 退出所有灯光效果回到"主页"的状态下
2. 单击"下键"，即可关机

![按键示意图](../assets/firefly-t1-02.png)

## 进入 & 退出灯光效果

**进入效果**
1. 拨动"左右键"，选择想要的效果
2. 单击"中键"，进入效果

**退出效果**
1. 在灯光效果界面的状态下
2. 长按"五向按键"的"中键"2秒后，即可退出效果，回到"主页"

## 连接电脑

数据线连接电脑后，会出现一个新的U盘，可以通过U盘来更新灯光效果程序或者读写文件。

:::tip
如果连接电脑后没有弹出U盘，请确保数据线支持数据传输（部分充电线不支持数据传输）。
:::

## 注意事项

- 关机后可直接存放，无需取出电池
- 插上电源后自动切换为外部供电，即使未安装电池，也可正常使用设备
- 为确保充电功率和数据传输的稳定性，推荐使用原装配套的数据线
