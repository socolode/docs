# 3D打印外壳

## 下载模型文件

萤火虫T1 的 3D 外壳模型文件已托管到官方 GitHub 仓库，可直接浏览并下载：

[萤火虫T1 3D 模型目录 · GitHub](https://github.com/socolode/firefly-t1/tree/main/3d-models)

仓库中按用途分类存放：

- `3d-models/case/`：主机外壳（STL + STEP 源文件）
- `3d-models/time-ring/`：时光环灯架、灯环结构件
- `3d-models/accessories/`：夹具、手柄、支架、灯罩等配件

## 打印建议

- **材料**：推荐使用 PLA（外壳类）或 PETG（受力配件）
- **层高**：0.2mm 即可获得良好效果
- **支撑**：根据模型结构可能需要支撑，悬空部位建议开启
- **填充**：15%-20% 填充率足够日常使用

## 组装指南

1. 打印完成后，清理支撑材料和毛边
2. 将萤火虫T1 主机放入外壳
3. 安装螺丝固定（如有）
4. 连接灯带/灯环后即可使用

## 个性化定制

如果你有 3D 建模经验，也可以基于仓库中的 STEP / Fusion 源文件进行修改，打造独一无二的外观。修改后的作品欢迎以 PR 形式贡献回官方仓库。
