# 兼容灯材与接线指南

## 支持的类型

### WS2812 / NeoPixel 灯带

最常见的智能灯带，每颗LED可独立控制颜色和亮度。适合光绘、氛围灯等场景。

| 规格 | 推荐 |
|------|------|
| 电压 | 5V |
| 密度 | 30灯/米、60灯/米、144灯/米 |
| 长度 | 建议不超过5米（视功率需求） |

<img src={require('./assets/ws2812-led-strip.png').default} alt="WS2812 智能灯带示意" style={{ borderRadius: '16px', maxWidth: '100%', display: 'block', margin: '24px auto' }} />

### WS2812 灯环

圆形灯环，适合做时钟、节奏灯、桌面装饰。

| 规格 | 适用场景 |
|------|----------|
| 12灯 | 小型氛围灯 |
| 16灯 | 时钟显示 |
| 24灯 | 丰富的时间显示效果 |
| 60灯 | 高分辨率时钟 |

<img src={require('./assets/ws2812-ring-16.png').default} alt="WS2812 16灯环示意" style={{ borderRadius: '16px', maxWidth: '100%', display: 'block', margin: '24px auto' }} />

### SK6812 RGBW 灯带

与 WS2812 协议兼容，但额外增加了独立的白色LED通道，可以调出更纯正的白光，也能在RGB混色基础上获得更柔和的色彩表现。适合需要高质量白光的氛围照明场景。

| 规格 | 说明 |
|------|------|
| 电压 | 5V |
| 通道 | RGBW（红、绿、蓝、白独立控制） |
| 白色类型 | 冷白、自然白、暖白可选 |

<img src={require('./assets/sk6812-rgbw-strip.png').default} alt="SK6812 RGBW 灯带示意" style={{ borderRadius: '16px', maxWidth: '100%', display: 'block', margin: '24px auto' }} />

### 其他兼容灯材

- WS2812B / WS2811 等兼容协议灯带
- 基于 WS2812 协议的 LED 矩阵、灯珠、像素屏
- 其他同协议的可寻址LED产品

## 5P-PIN 接口定义

萤火虫T1 的扩展接口为 5P-PIN 座，显示屏面为"正面"，设备共有两个 5P-PIN 接口（上方接口与左侧接口），引脚对应关系见下表，实物请参考附图。

### 5P-PIN（上）

引脚顺序为正面"从左往右"。

| PIN | 功能 | 控制端口 |
|-----|------|----------|
| PIN1 | VCC输出（5V）<br/>高阻态关断，低电平接通 | GPIO43 |
| PIN2 | GPIO | GPIO14 |
| PIN3 | GND | 直连GND |
| PIN4 | GND | 直连GND |
| PIN5 | GPIO | GPIO13 |

### 5P-PIN（左侧）

引脚顺序为正面"从上往下"。

| PIN | 功能 | 控制端口 |
|-----|------|----------|
| PIN1 | VCC输出（5V）<br/>高阻态关断，低电平接通 | GPIO43 |
| PIN2 | GND | 直连GND |
| PIN3 | GPIO | GPIO42 |
| PIN4 | GPIO | GPIO15 |
| PIN5 | GPIO | GPIO16 |

## 接线步骤

### WS2812 灯材的常用引脚

WS2812 这类可寻址灯带/灯环，通常只有三根引脚需要接线：

| 引脚 | 名称 | 说明 |
|------|------|------|
| 电源 | 5V / VCC | 供电正极 |
| 信号 | DIN / DI | 数据信号输入 |
| 地 | GND | 电源地 |

### 接线方式

接线其实很简单：把灯材的三根引脚，对应接到萤火虫T1 接口的电源、地，以及**任意一个信号（GPIO）引脚**即可。

| 萤火虫T1 接口 | 灯材对应引脚 |
|----------|-----------|
| VCC（5V） | 5V / VCC（电源） |
| GPIO（任意信号引脚） | DIN / DI（信号） |
| GND | GND（地） |

**举例**：接到「5P-PIN（上）」接口，信号接 PIN5（GPIO13）：

| 灯材引脚 | 5P-PIN（上）接口 |
|----------|-----------------|
| 5V / VCC（电源） | PIN1 · VCC输出（5V） |
| DIN / DI（信号） | PIN5 · GPIO13 |
| GND（地） | PIN3 · GND |

信号可以接到任意一个 GPIO 引脚，效果相同。

萤火虫T1 的 5P 接口标配了一根转接线，直接连接灯带即可。

### 接线步骤

1. 确认萤火虫T1 已关机
2. 将 5P 转接线插入萤火虫T1 的扩展接口
3. 将转接线的电源、地、信号三端，分别连接到灯带/灯环的对应引脚
4. 检查接线无误后开机

## 选购建议

- **光绘**：推荐 144灯/米 的高密度灯带，光轨更细腻
- **桌面时钟**：推荐 16-24灯 灯环，显示效果清晰
- **节奏灯**：推荐 24灯 以上灯环，频率响应更丰富
- **氛围灯墙**：推荐 30灯/米 灯带，平衡效果和功耗

## 注意事项

- 请确保灯材工作电压为 5V
- 长时间使用高密度灯带时，注意散热
- 接线前请确保设备已关机
- 避免在通电状态下插拔接口
- 大功率灯材建议使用外接电源
