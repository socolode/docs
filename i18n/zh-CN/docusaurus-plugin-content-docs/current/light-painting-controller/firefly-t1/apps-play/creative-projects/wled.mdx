## 什么是 WLED

**WLED** 是一个非常流行的开源 LED 控制固件（运行在 ESP32 / ESP8266 等芯片上），被全球 DIY 玩家广泛使用，是地址码 LED 社区事实上的标准工具。它拥有：

- **200+ 内置动画效果** — 经典动画、音频响应、2D 矩阵特效等
- **分段控制** — 把一条 LED 灯带拆成多段，每段独立颜色和效果
- **预设与播放列表** — 一键切换场景，支持定时/触发切换
- **网页 UI + 手机 App** — 无需写代码，手机/电脑浏览器就能调颜色、选效果
- **多种协议接入** — 原生支持 E1.31 (sACN) / Art-Net / DDP / MQTT / Home Assistant
- **社区庞大** — 自定义效果（Usermods）、教程、第三方控制器非常多

## 萤火虫T1 接入 WLED 后能做什么

完成集成后，你可以在萤火虫T1 上使用 WLED 的完整生态，例如：

- 直接通过 WLED 的网页界面 / 手机 App 实时调色、切换效果
- 接入智能家居系统（Home Assistant、小爱同学、HomeKit 等）
- 作为 DMX/E1.31 像素节点，被专业灯光软件（xLights、Jinx!、Vixen 等）控制
- 音频响应效果、预设播放列表、分段混合叠加等高级玩法
