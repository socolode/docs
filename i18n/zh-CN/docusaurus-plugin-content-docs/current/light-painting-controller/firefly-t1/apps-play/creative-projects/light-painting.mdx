# 光绘棒

将萤火虫T1 与灯带、灯棒和专用底座组装成光绘棒，你就可以在夜空中画出光轨，拍出令人惊艳的光绘照片。

## 你需要

- 萤火虫T1 主机
- 灯带
- 光绘棒专用底座（<Link to="../3d-printing">3D打印文件</Link>里面有）
- 灯棒（可以自制）

## 准备工作

- 组装好的光绘棒
- 相机/手机
- 三脚架
- 找一个全黑或者暗光环境

## 常见问题

### 光轨不够亮？
- 增加灯带亮度（调整效果参数）
- 使用更高密度的灯带（144灯/米）
- 放慢挥动速度

### 背景太亮？
- 降低 ISO
- 缩小光圈（增大 f 值）
- 选择更暗的环境
