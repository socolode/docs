# 光绘摄影

用萤火虫T1 接上灯带，你就可以在夜空中画出光轨，拍出令人惊艳的光绘照片。

## 你需要

- 萤火虫T1 主机
- WS2812 灯带（推荐 144灯/米 高密度）
- 三脚架（固定相机用）
- 支持长曝光的相机或手机（手动模式）
- 暗光环境

## 准备工作

1. 按照<Link to="../compatible-leds-wiring">接线指南</Link>连接灯带
2. 安装一个适合光绘的灯光效果文件
3. 设置相机：M档（手动模式），快门 2-30 秒，ISO 100-400，光圈 f/8-f/11
4. 找一个全黑或暗光环境

## 拍摄技巧

### 基础光绘

将萤火虫T1 + 灯带作为画笔，在镜头前挥动。快门开启期间，灯带划过的轨迹都会记录在照片中。

### 创意光绘

- **多色光轨**：使用支持颜色渐变的效果，挥动时变换颜色
- **文字光绘**：在空中书写文字（注意是镜像的）
- **轮廓光绘**：围绕物体勾勒轮廓

## 常见问题

### 光轨不够亮？
- 增加灯带亮度（调整效果参数）
- 使用更高密度的灯带（144灯/米）
- 放慢挥动速度

### 背景太亮？
- 降低 ISO
- 缩小光圈（增大 f 值）
- 选择更暗的环境
