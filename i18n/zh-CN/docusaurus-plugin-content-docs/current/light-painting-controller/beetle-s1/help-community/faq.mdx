# 独角仙S1 常见问题

## 开机与关机

### 问：独角仙S1 无法开机怎么办？
**答：** 请检查以下事项：
1. 电池是否有电？尝试充电后再开机。
2. 长按"中键"2秒以上，确保操作正确。
3. 如果仍然无法开机，尝试连接充电器，确认是否电池问题。

### 问：如何关机？
**答：** 在主页（非灯光效果界面）状态下，单击"下键"即可关机。

### 问：会自动关机吗？
**答：** 会。S1 默认静止 5 分钟自动关机，省电又省心。

## 充电与供电

### 问：充电需要多长时间？
**答：** 使用 5V/2A 以上充电器，约 2 小时可充满。充电时快充口红灯亮，充满后熄灭。

### 问：可以边充电边使用吗？
**答：** 可以。插上电源后自动切换为外部供电模式，即使电池没电也可正常使用。

### 问：两个 Type-C 口有什么区别？
**答：** 一个快充口（充电专用），一个数据口（连接电脑传输文件）。充电和数据互不干扰。

## 连接电脑

### 问：连接电脑后没有弹出 U 盘？
**答：** 请确保：
1. 使用的是数据口（而非快充口）。
2. 数据线支持数据传输（部分充电线不支持数据传输）。
3. 设备已开机。
4. 尝试更换 USB 接口或数据线。

### 问：电脑识别不到设备？
**答：** 如果是固件烧录模式，需要先关机，按住"右方向键"再连接电脑。

## 灯光效果

### 问：如何安装新的灯光效果？
**答：** 参考<Link to="../effects-projects/effect-list-install">效果一览与安装</Link>教程，通过 U 盘拖拽安装即可。

### 问：添加效果后没有显示？
**答：** 请检查是否正确填写了 `config.json` 文件。具体配置方法见效果安装教程。

### 问：如何删除不需要的效果？
**答：** 连接电脑进入 U 盘模式，删除 `/apps/` 下对应效果的文件夹，并从 `config.json` 中移除相关配置项即可。

## 灯材与接线

### 问：独角仙S1 支持哪些灯带？
**答：** 支持 WS2812 等常见智能灯带/灯环，通过 XT30 接口连接。详细接线指南请参考<Link to="../effects-projects/compatible-leds-wiring">兼容灯材与接线</Link>章节。

### 问：XT30 接口怎么接线？
**答：** XT30(2+2) 端子包含 2 个大电流电源端子和 2 个控制信号端子。S1 标配了转接线，直接连接灯带即可。详见接线指南。

## 扩展与编程

### 问：S1 和 T1 的 API 通用吗？
**答：** 基本通用。S1 和 T1 运行同一套 MicroPython 系统，自定义 API 也基本一致。但 S1 没有内置麦克风和 9 轴传感器，依赖这些硬件的效果无法直接运行，需要外接模块。

### 问：4PIN 接口能接什么？
**答：** 4PIN 接口支持 SPI/I2C/UART/GPIO，可以外接各种传感器模块，如麦克风模块、IMU 模块、显示屏等。
