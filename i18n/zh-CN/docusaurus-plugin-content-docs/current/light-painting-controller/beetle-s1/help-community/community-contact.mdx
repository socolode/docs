## 社区平台

Discord 社区是独角仙S1 用户的大本营，在这里你可以：

- **分享作品**：展示你的灯光效果和创意玩法
- **交流经验**：与其他创作者交流技巧和心得
- **获取帮助**：遇到问题时，社区伙伴会热心帮忙
- **参与开发**：参与固件和效果的开发讨论，直接向开发者反馈建议

加入 Discord 后，记得先查看 #公告 和 #入门指南 频道，了解社区规则和资源索引。

## 技术支持

如果你在使用过程中遇到问题，可以按以下顺序寻求帮助：

1. 先查阅<Link to="./faq">常见问题 FAQ</Link>——大部分问题已有答案
2. 在 Discord 社区搜索或提问——社区伙伴通常很快回复
3. 通过 GitHub Issues 提交 Bug 报告或功能建议——开发者会定期跟进
