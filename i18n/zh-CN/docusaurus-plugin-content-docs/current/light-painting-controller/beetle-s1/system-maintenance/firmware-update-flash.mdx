# 固件更新与系统烧录

## 如何检查固件版本

开机后，在主页界面即可看到当前固件版本号。如果遇到功能异常或想体验新功能，可以尝试更新固件。

## 固件下载

最新固件文件可通过以下链接获取：

[独角仙S1 所有固件 - 百度网盘](https://pan.baidu.com/s/19I89DSC0XkglKS-24e6vkA?pwd=j99s)

## 更新步骤

### 通过 Thonny 烧录固件

1. 安装 Thonny 编程工具
2. 下载固件
3. 刷写步骤：
   - 先关机，按住"右方向键"
   - 用 USB 数据线（数据口）连接电脑
   - 打开 Thonny 配置解释器
   - 点击"安装/更新 MicroPython"
   - 选择固件文件和 COM 端口

:::caution 注意
如目标端口没有独角仙S1 的 COM 端口，可能是在 USB 连接电脑时没有按住按键的原因。
:::

## 更新建议

- 更新前请确保设备电量充足
- 如无特殊需求，建议使用最新稳定版固件
- 更新后如果遇到问题，可以刷回之前的版本
