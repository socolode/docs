# 兼容灯材与接线指南

独角仙S1 配备 XT30(2+2) 端子，支持大电流输出，可以驱动更多、更长的灯带。

## 支持的类型

### WS2812 / NeoPixel 灯带

最常见的智能灯带，每颗 LED 可独立控制颜色和亮度。适合光绘、氛围灯等场景。

| 规格 | 推荐 |
|------|------|
| 电压 | 5V |
| 密度 | 30灯/米、60灯/米、144灯/米 |
| 长度 | 建议不超过10米（S1 高功率输出可驱动更长灯带） |

### WS2812 灯环

圆形灯环，适合做时钟、节奏灯、桌面装饰。

| 规格 | 适用场景 |
|------|----------|
| 12灯 | 小型氛围灯 |
| 16灯 | 时钟显示 |
| 24灯 | 丰富的时间显示效果 |
| 60灯 | 高分辨率时钟 |

### 其他兼容灯材

- SK6812 (RGBW，支持独立白色通道)
- 其他基于 WS2812 协议的灯带/灯环
- 高功率灯带（需要大电流驱动的灯带）

## XT30(2+2) 接口定义

S1 的主输出接口为 XT30(2+2) 端子，包含 2 个大电流电源端子和 2 个高速控制信号端子。

| 端子 | 信号 | 说明 |
|------|------|------|
| 大电流+ | 5V | 电源正极（大电流） |
| 大电流- | GND | 电源地 |
| 信号+ | DATA | 控制信号 |
| 信号- | GND | 信号地 |

## 接线步骤

### 标准接线

S1 标配了一根 XT30 转接线，直接连接灯带即可。

| 独角仙S1 | 灯带/灯环 |
|----------|-----------|
| 5V (大电流+) | 5V / VCC |
| DATA (信号+) | DIN / DI |
| GND (大电流- / 信号-) | GND |

### 接线步骤

1. 确认独角仙S1 已关机
2. 将 XT30 转接线插入 S1 的 XT30 接口
3. 将转接线的另一端连接到灯带/灯环的对应接口
4. 检查接线无误后开机

## 选购建议

- **光绘**：推荐 144灯/米 的高密度灯带，光轨更细腻
- **光绘棒套件**：配合 S1 官方光绘棒套件使用，效果最佳
- **桌面时钟**：推荐 16-24灯 灯环，显示效果清晰
- **节奏灯**：推荐 24灯 以上灯环，频率响应更丰富
- **大型灯光装置**：S1 高功率输出，可驱动更长灯带

## 注意事项

- 请确保灯材工作电压为 5V
- S1 支持大电流输出，但长时间使用高密度、长灯带时仍建议注意散热
- 接线前请确保设备已关机
- 避免在通电状态下插拔接口
- XT30 接口有防呆设计，请勿强行反接
