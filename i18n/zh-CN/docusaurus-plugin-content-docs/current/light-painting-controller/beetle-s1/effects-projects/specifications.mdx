# 规格参数

## 电子电气特性

| 参数 | 最小值 | 典型值 | 最大值 | 单位 |
|------|--------|--------|--------|------|
| 输入电压 | 4.5 | 5.0 | 5.5 | V |
| 输入电流（快充口） | 0.5 | 2.0 | 3.0 | A |
| 输出电压（XT30） | 4.75 | 5.0 | 5.25 | V |
| 输出电流（XT30） | - | 3.0 | 5.0 | A |
| 快充接口 | - | Type-C USB | - | - |
| 数据接口 | - | Type-C USB | - | - |
| 电源类型 | 内置锂电池 / USB供电 | | | |

## 接口定义

### XT30(2+2) 主输出

| 端子 | 信号 | 说明 |
|------|------|------|
| 大电流+ | 5V | 电源正极（大电流） |
| 大电流- | GND | 电源地 |
| 信号+ | DATA | 控制信号 |
| 信号- | GND | 信号地 |

### XH2.54-4P 扩展接口

| 引脚 | 信号 | 说明 |
|------|------|------|
| 1 | 3.3V | 电源输出 |
| 2 | SDA / MOSI | I2C 数据 / SPI 主出从入 |
| 3 | SCL / SCK | I2C 时钟 / SPI 时钟 |
| 4 | GND | 地线 |
