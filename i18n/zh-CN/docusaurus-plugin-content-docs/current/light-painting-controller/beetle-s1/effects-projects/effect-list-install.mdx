# 效果一览与安装

## 效果一览

效果库是一个在线表格，提供各种效果可用的灯光效果下载。请访问 [独角仙S1 效果库](https://socolode.yuque.com/ogwgwg/xnlyru) 查看完整的效果列表和下载链接。

:::note 注意
T1 效果库中的部分效果依赖内置麦克风（声控效果）和 9 轴传感器（体感交互）。S1 没有这些内置硬件，这些效果无法直接运行。如需使用类似功能，请参考<Link to="../app-development/s1-hardware-programming">S1 硬件适配编程</Link>章节，通过外接模块实现。
:::

## 安装灯光效果

### 1. 下载效果文件

打开效果库，选择一个喜欢的灯光效果并下载。

### 2. 连接电脑

用 USB 数据线（数据口）将独角仙S1 连接到电脑。等待几秒钟，电脑上会出现一个新的 U 盘。

### 3. 添加效果

1. 把下载回来的灯光效果文件，直接放入 U 盘的 `/apps` 文件夹里面

### 4. 注册效果（启用效果）

1. 用电脑的文本编辑工具，打开 U 盘里面的 `apps/config.json` 文件
2. 在 `config.json` 文件里面，添加新的效果信息

**添加说明：**

每个灯光效果的基本信息需要按照如下格式填写：

- `"name"`: 效果名称
- `"folder"`: 效果文件夹路径
- `"enabled"`: 是否启用效果

:::note 注意
- 必须填写 `config.json` 文件，才能显示效果图标以及使用效果
- 元素列表的顺序，就是效果的显示顺序
:::

### 5. 启动效果

如添加和配置成功之后，开机拨动左右键选择效果，单击"中键"即可启动新效果！
