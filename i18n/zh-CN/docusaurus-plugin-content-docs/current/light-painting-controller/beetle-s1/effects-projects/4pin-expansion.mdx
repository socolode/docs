# 4PIN 扩展接口应用

独角仙S1 提供一个 XH2.54-4P 多功能扩展接口，支持 SPI/I2C/UART/GPIO 通信协议，可以外接各种传感器和外围设备。

## 接口定义

| 引脚 | 信号 | 说明 |
|------|------|------|
| 1 | 3.3V | 电源输出 |
| 2 | SDA / MOSI | I2C 数据 / SPI 主出从入 |
| 3 | SCL / SCK | I2C 时钟 / SPI 时钟 |
| 4 | GND | 地线 |

## 支持的协议

| 协议 | 典型应用 |
|------|----------|
| SPI | 高速数据传输，外接显示屏、传感器模块 |
| I2C | 连接传感器（温湿度、气压、IMU等） |
| UART | 串口通信，连接 GPS、蓝牙模块等 |
| GPIO | 通用输入输出，控制继电器、按键等 |

## 外接传感器实现声控效果

S1 没有内置麦克风，但通过 4PIN 接口外接麦克风模块，即可实现声控灯光效果。

**所需材料：**
- 驻极体麦克风模块（MAX9814 或类似）
- 杜邦线

**接线：**

| 4PIN 接口 | 麦克风模块 |
|-----------|-----------|
| 3.3V | VCC |
| SDA/MOSI | 模拟输出（接 GPIO） |
| GND | GND |

## 外接 IMU 实现体感交互

通过 4PIN 接口外接 IMU（惯性测量单元）模块，可实现体感控制灯光效果。

**所需材料：**
- MPU6050 或类似 IMU 模块
- 杜邦线

**接线：**

| 4PIN 接口 | IMU 模块 |
|-----------|----------|
| 3.3V | VCC |
| SDA/MOSI | SDA |
| SCL/SCK | SCL |
| GND | GND |

## 编程示例

```python
from machine import Pin, I2C
import time

# 初始化 I2C
i2c = I2C(0, scl=Pin(3), sda=Pin(2), freq=400000)

# 扫描 I2C 设备
devices = i2c.scan()
print("I2C devices:", [hex(addr) for addr in devices])
```
