# 光绘棒套件

独角仙S1 的核心场景就是光绘棒。配合官方光绘棒套件，手柄秒变专业光绘棒，在夜空中画出令人惊叹的光轨。

## 套件包含

| 物品 | 说明 |
|------|------|
| 独角仙S1 主机 | 手柄形状的灯光控制器 |
| 光绘棒灯带 | 高密度灯带，专为光绘优化 |
| XT30 转接线 | 连接主机和灯带 |
| 固定支架 | 将灯带固定在手柄前方 |

## 组装步骤

1. 将灯带通过固定支架安装在 S1 手柄前方
2. 使用 XT30 转接线连接主机和灯带
3. 检查接线无误后开机
4. 选择一个光绘专用效果，开始创作

## 光绘拍摄技巧

### 基础光绘

将 S1 光绘棒作为画笔，在镜头前挥动。快门开启期间，灯带划过的轨迹都会记录在照片中。

### 创意光绘

- **多色光轨**：使用支持颜色渐变的效果，挥动时变换颜色
- **文字光绘**：在空中书写文字（注意是镜像的）
- **轮廓光绘**：围绕物体勾勒轮廓
- **多人光绘**：多支 S1 同时创作，画面更丰富

### 相机设置建议

| 参数 | 建议值 |
|------|--------|
| 拍摄模式 | M档（手动模式） |
| 快门速度 | 2-30 秒 |
| ISO | 100-400 |
| 光圈 | f/8-f/11 |
| 对焦 | 手动对焦，预先对焦到拍摄区域 |
