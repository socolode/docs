# 创意玩法教程

独角仙S1 的一体式手柄设计 + 高功率输出，让创意玩法更加自由。

## 光绘摄影

S1 的核心场景。配合光绘棒套件，在夜空中画出光轨。

详细教程请参考<Link to="./light-painting-wand">光绘棒套件</Link>章节。

## 手持氛围灯

S1 的手柄形状握持舒适，拿在手里就是一支炫酷的氛围灯。

- 适合派对、音乐节、露营等场景
- 选择彩色渐变或节奏灯效果
- 握在手中挥动，营造氛围

## 桌面灯光装置

通过 XT30 接口连接灯环或灯带，放在桌面上就是一道风景。

- **桌面时钟**：配合灯环显示时间
- **节奏灯**：外接麦克风模块（通过 4PIN 接口），实现声控节奏灯
- **氛围灯**：选择渐变或呼吸效果，打造桌面氛围

## 大型灯光装置

S1 的高功率输出可以驱动更长、更多的灯带，适合：

- 活动布景灯光
- 户外装置艺术
- 派对灯光装饰

## 更多创意

- **道具灯光**：将 S1 固定在道具上，作为角色扮演或表演的灯光道具
- **互动装置**：通过 4PIN 接口外接传感器，制作互动灯光装置
- **多机联动**：多台 S1 同步使用，打造更丰富的灯光画面
