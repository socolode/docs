# 产品特点与卖点

## 一体式手柄设计

无需底座，开箱即用。手柄形状符合人体工学，握持舒适，适合长时间光绘创作。

- 一体式机身，无需任何组装
- 人体工学手柄，握持舒适
- 手持即可创作，摆脱线缆束缚

## 高功率输出

配备 XT30(2+2) 端子，支持大电流输出，驱动高密度灯带和大型灯光装置轻松自如。

- 大电流驱动，支持更长灯带
- XT30 防呆接口，接线安全可靠
- 适合专业光绘和大型灯光装置

## 双 Type-C 设计

一个快充口，一个数据口，充电和数据传输互不干扰。

- 快充口：红灯充电中，灭灯已充满
- 数据口：连接电脑 U 盘模式，传文件、装效果
- 充电时不影响数据传输

## 4PIN 扩展接口

XH2.54-4P 多功能扩展接口，支持 SPI/I2C/UART/GPIO 协议，可外接各种传感器和外围设备。

- 外接麦克风模块，实现声控节奏灯
- 外接 IMU 模块，实现体感交互
- 外接传感器，制作互动灯光装置

## 圆形彩屏 + 实体按键

圆形彩色显示屏，配合功能键/左右键/中键/下键，操作直观，反馈清晰。

- 圆形彩屏，效果图标一目了然
- 实体按键，盲操作无压力
- 操作逻辑简单，上手即用

## 开源可编程

基于 MicroPython 生态，懂 Python 就能自己写灯光效果。开发上手简单，社区资源丰富。

- 完整的自定义 API
- MicroPython 标准库支持
- 开源固件，持续更新

## 自动关机

静止 5 分钟自动关机，省电又省心。不用担心忘记关机耗尽电池。
