# 这是什么？

独角仙S1 是一个手柄形状的专业手持灯光控制器。接上灯带，它就是光绘棒；装上灯环，它就是桌面氛围灯。拖一个文件进去就能切换灯光效果，想改颜色和速度？调几个数字就行。懂 Python 的话，还能自己写效果。

手柄形状，一体式设计，拿起来就能用——不需要底座、不需要外壳、不需要任何组装。

## 你拿到手的是

| 物品 | 说明 |
|------|------|
| 独角仙S1 主机 | 手柄形状的一体式灯光控制器，自带圆形彩屏和按键 |
| XT30 转接线 | 用于连接灯带或光绘棒配件 |
| Type-C 数据线（充电用） | 快充充电线 |
| Type-C 数据线（数据用） | 连接电脑传输文件 |
