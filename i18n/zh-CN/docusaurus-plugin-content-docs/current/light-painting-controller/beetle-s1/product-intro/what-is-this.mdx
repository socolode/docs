# 独角仙S1 产品介绍

## 独角仙S1是什么？

独角仙S1 是一款手柄形态的专业灯光控制器，也是萤火虫T1 的更专业版本。它不只是一支光绘棒——配合 XT30 大功率接口，它能驱动各种灯具，胜任光绘、灯光装置、氛围布光等多样化的灯光控制场景。

它使用 Python 语言来控制灯光——像往 U 盘里拖文件一样简单，无需安装任何复杂环境，直接用 AI 生成想要的 Python 脚本拖进去就能控制。通过 4PIN 扩展接口，还能连接各类拓展配件与传感器，开发出更多玩法。特殊的蜗牛云台结构，让你可以拼接各种灯具与配件，灵活调整角度与安装方式。更多丰富的外扩配件还在持续开发中，敬请期待。

## 适合谁用？

独角仙S1 面向喜欢玩灯、想做出独特灯光效果的人——从新手到进阶创作者，都能找到自己的玩法：

- **光绘摄影爱好者**：想拍出专业光轨照片，又不想被复杂器材绊住
- **灯光创客与 DIY 玩家**：喜欢用 Python 编写自己的灯光程序，打造独一无二的装置
- **内容创作者**：直播、布景、氛围营造，需要一盏灵活又专业的灯光控制器
- **零基础新手**：开箱即用、编程简单，迈出玩灯第一步也毫无压力

## 主要特点

### 高功率输出

- 配备 XT30(2+2) 大功率接口，大电流驱动，轻松带动更长、更多的灯带
- XT30 防呆接口，接线安全可靠
- 胜任光绘、氛围布光、大型灯光装置等多种场景

### 极简编程

- 使用 Python 语言，对普通人非常友好，无需编程基础也能上手
- 像往 U 盘里拖文件一样简单——用 AI 生成 Python 脚本，直接拖进去就能控制灯光
- 无需安装繁杂的环境，即插即用、开箱就能玩

<img src={require('../assets/beetle-s1-programming.png').default} alt="独角仙S1 Python 编程示意" style={{ borderRadius: '16px', maxWidth: '100%', display: 'block', margin: '24px auto' }} />

### 灵活拓展

- 4PIN 扩展接口，支持 SPI/I2C/UART/GPIO 协议
- 外接麦克风、IMU 等传感器，解锁声控、体感等交互玩法

### 蜗牛云台结构

- 可拼接各种灯具与配件，灵活调整角度与安装方式

### 双 Type-C 设计

- 一个快充口、一个数据口，充电与数据传输互不干扰
- 数据口 U 盘模式，传文件、装效果更方便

### 彩色屏幕 + 按键

- 彩色屏幕：效果图标一目了然，当前状态清晰可见
- 特色五向按键 + 自定义按键：选择、确认、返回操作顺手，逻辑清晰
- 按键反馈明确，盲操作也无压力

### 自动关机

- 静止 5 分钟自动关机，省电又省心
