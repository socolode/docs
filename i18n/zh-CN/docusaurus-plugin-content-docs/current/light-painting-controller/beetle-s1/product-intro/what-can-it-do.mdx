# 它能做什么？

## 光绘摄影

独角仙S1 的核心场景。配合光绘棒套件，在夜空中画出光轨，拍出令人惊艳的光绘照片。手柄形状握持舒适，长时间创作也不累。

**你需要：** 独角仙S1 + 光绘棒套件 + 三脚架 + 支持长曝光的相机/手机

详细教程请参考<Link to="../effects-projects/light-painting-wand">光绘棒套件</Link>。

## 桌面氛围灯

装上灯环，独角仙S1 变身桌面氛围灯。渐变、呼吸、节奏律动——放在桌面上，它就是最抢眼的装饰。

**你需要：** 独角仙S1 + 灯环

## 手持炫彩灯

手柄形状拿在手里就是一支炫酷的氛围灯。适合派对、音乐节、露营等场景，握在手中挥动，营造氛围。

**你需要：** 独角仙S1 + 灯带

## 大型灯光装置

高功率输出可以驱动更长、更多的灯带，适合活动布景、派对装饰、户外装置艺术。

**你需要：** 独角仙S1 + 多组灯带

## 创意互动装置

通过 4PIN 扩展接口外接传感器，可以制作互动灯光装置——声控节奏灯、体感交互光效、智能感应灯等。

**你需要：** 独角仙S1 + 传感器模块 + 4PIN 接线

详细教程请参考<Link to="../effects-projects/4pin-expansion">4PIN 扩展接口应用</Link>。

## 更多可能…

这只是开始。结合 3D 打印外壳和开源编程，你还可以做出更多创意作品。独角仙S1 的玩法由你的想象力决定。
