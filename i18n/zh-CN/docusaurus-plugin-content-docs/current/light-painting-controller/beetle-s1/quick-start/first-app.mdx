# 安装第一个应用

5 分钟让你的独角仙S1 亮起来。跟着下面几步，就能装好并运行第一个应用。

## 第一步：下载应用

打开<Link to="../effects-projects/effect-list-install">应用一览与安装</Link>或[官方 GitHub 仓库](https://github.com/socolode/beetle-s1)，选择一个喜欢的灯光应用并下载。

## 第二步：上传到独角仙S1

用 USB 数据线把独角仙S1 连接到电脑，然后把下载好的应用上传到独角仙S1 里面。

## 第三步：连接灯条

把灯条正确接到独角仙S1 的接口上。接线方法请参考<Link to="../effects-projects/compatible-leds-wiring">兼容灯材与接线</Link>。

## 第四步：体验应用

开机运行，在灯条上欣赏下载应用的彩色灯光应用。

## 第五步：学习自定义应用

想要自己定义灯光应用？前往<Link to="../../app-development/first-script">编写第一个应用</Link>，学习从零开始打造专属应用。
