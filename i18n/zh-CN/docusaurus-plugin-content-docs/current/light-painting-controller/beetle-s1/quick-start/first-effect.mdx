# 安装第一个效果

5 分钟让你的独角仙S1 亮起来。

## 第一步：下载效果文件

打开<Link to="../effects-projects/effect-list-install">效果一览与安装</Link>，选择一个喜欢的灯光效果并下载。

## 第二步：连接电脑

用 USB 数据线（数据口）将独角仙S1 连接到电脑。等待几秒钟，电脑上会出现一个新的 U 盘。

## 第三步：拖拽安装

1. 打开 U 盘，找到 `/apps` 文件夹
2. 将下载的效果文件拖入 `/apps` 文件夹
3. 用文本编辑器打开 `/apps/config.json`，按照格式添加新效果的信息

## 第四步：体验效果

1. 安全弹出 U 盘，拔掉数据线
2. 开机后，拨动左右键选择新效果
3. 单击中键，灯光亮起！

详细安装教程请参考<Link to="../effects-projects/effect-list-install">效果一览与安装</Link>。
