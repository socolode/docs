# S1 硬件适配编程

本节介绍如何通过 4PIN 扩展接口编写外设驱动程序和适配外部传感器。

## 4PIN 接口编程基础

S1 的 XH2.54-4P 扩展接口支持 SPI/I2C/UART/GPIO 协议。

### I2C 通信示例

```python
from machine import Pin, I2C

# 初始化 I2C
i2c = I2C(0, scl=Pin(3), sda=Pin(2), freq=400000)

# 扫描 I2C 设备
devices = i2c.scan()
print("I2C devices:", [hex(addr) for addr in devices])
```

### GPIO 控制示例

```python
from machine import Pin

# 设置 GPIO
ext_pin = Pin(2, Pin.OUT)
ext_pin.value(1)  # 输出高电平
```

## 外接麦克风模块（声控效果）

S1 没有内置麦克风，需要通过 4PIN 接口外接麦克风模块实现声控效果。

### 接线

| 4PIN 接口 | 麦克风模块 |
|-----------|-----------|
| 3.3V | VCC |
| SDA/MOSI | 模拟输出 |
| GND | GND |

### 示例代码

```python
from machine import Pin, ADC
import time

# 初始化 ADC
mic = ADC(Pin(2))

while True:
    value = mic.read()
    # 根据声音强度控制灯光
    brightness = value // 4  # 0-255 映射
    print("Sound level:", brightness)
    time.sleep_ms(100)
```

## 外接 IMU 模块（体感交互）

通过 4PIN 接口外接 MPU6050 等 IMU 模块。

### 接线

| 4PIN 接口 | IMU 模块 |
|-----------|----------|
| 3.3V | VCC |
| SDA/MOSI | SDA |
| SCL/SCK | SCL |
| GND | GND |

### 示例代码

```python
from machine import Pin, I2C
import time

# MPU6050 地址
MPU6050_ADDR = 0x68

i2c = I2C(0, scl=Pin(3), sda=Pin(2), freq=400000)

# 唤醒 MPU6050
i2c.writeto_mem(MPU6050_ADDR, 0x6B, b'\x00')

while True:
    # 读取加速度数据
    data = i2c.readfrom_mem(MPU6050_ADDR, 0x3B, 6)
    ax = (data[0] << 8) | data[1]
    ay = (data[2] << 8) | data[3]
    az = (data[4] << 8) | data[5]
    print("Accel:", ax, ay, az)
    time.sleep_ms(100)
```

## 注意事项

- 4PIN 接口输出 3.3V，外接模块需支持 3.3V 供电
- 外接模块时请注意接线方向，避免短路
- 建议在关机状态下接线，接好后再开机
