# MicroPython API

独角仙S1 基于 MicroPython 运行，支持大部分 MicroPython 标准库。以下是在灯光效果开发中常用的模块。

## 常用标准库

### `machine` — 硬件控制

```python
from machine import Pin, PWM, ADC

# 设置GPIO引脚
pin = Pin(4, Pin.OUT)
pin.value(1)  # 输出高电平

# PWM控制
pwm = PWM(Pin(5))
pwm.freq(1000)  # 设置频率
pwm.duty(512)   # 设置占空比
```

### `time` — 时间控制

```python
import time

time.sleep(1)        # 延时1秒
time.sleep_ms(500)   # 延时500毫秒
time.ticks_ms()      # 获取当前毫秒数
```

### `math` — 数学运算

```python
import math

# 用于生成平滑的灯光动画
value = math.sin(angle)  # 正弦波
value = math.cos(angle)  # 余弦波
```
