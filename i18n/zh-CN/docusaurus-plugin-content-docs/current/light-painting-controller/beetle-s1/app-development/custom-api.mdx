# 自定义API

独角仙S1 基于 MicroPython 运行，API 与萤火虫T1 基本通用。以下是为 S1 适配的自定义 API 参考。

## 屏幕显示

### `display_text(text, x, y, color)`

在屏幕上显示文字。

- `text` (str): 要显示的文本
- `x` (int): 横坐标
- `y` (int): 纵坐标
- `color` (int, 可选): 颜色值，默认白色

### `display_clear()`

清空屏幕内容。

## 按键输入

### `button_was_pressed(button_id)`

检测指定按键是否被按下。

- `button_id` (str): 按键标识，可选值：`"up"`, `"down"`, `"left"`, `"right"`, `"center"`, `"function"`

返回 `True` 或 `False`。

## LED控制

### `set_led(index, r, g, b)`

设置单个LED的颜色。

- `index` (int): LED编号
- `r` (int): 红色值 (0-255)
- `g` (int): 绿色值 (0-255)
- `b` (int): 蓝色值 (0-255)

### `set_all_leds(r, g, b)`

设置所有LED为同一颜色。
