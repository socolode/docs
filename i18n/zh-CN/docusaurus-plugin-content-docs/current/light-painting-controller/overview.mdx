# 光码系列概览

Socolode 光码（LightCoding）系列是一套灯光控制器产品线，涵盖从入门轻巧到专业手持的多种形态。无论你是光绘摄影爱好者、桌搭氛围玩家，还是互动灯光装置创作者，总有一款适合你。

---

## 产品阵容

### 萤火虫T1

掌心大小的灯光控制主机，轻巧便携，适合入门玩家和随身创作。

- **形态**：方形主机，掌心大小，内置屏幕和五向按键
- **供电**：内置 18650 锂电池，Type-C 充电
- **适用场景**：户外光绘、桌搭氛围、派对布景
- **特点**：即插即用，无需编程基础，5 分钟上手

→ <Link to="../light-painting-controller/firefly-t1/product-intro/what-is-this">了解萤火虫T1</Link>

### 独角仙S1

手柄形状的专业手持灯光控制器，一体式设计，适合专业创作和长时间使用。

- **形态**：手柄形状一体式机身，自带圆形彩屏和实体按键
- **供电**：双 Type-C（快充口 + 数据口），大电流 XT30 输出
- **适用场景**：专业光绘、大型灯光装置、互动装置
- **特点**：高功率输出、4PIN 扩展接口、人体工学握持

→ <Link to="../light-painting-controller/beetle-s1/product-intro/what-is-this">了解独角仙S1</Link>

---

## 共同特性

两款控制器共享以下核心能力：

- **即插即用**：U 盘模式拖拽安装效果文件，无需焊接或编程基础
- **开源可编程**：基于 MicroPython 生态，支持自定义 API 编写灯光效果
- **灯带兼容**：支持市面上常见的 WS2812 灯带/灯环
- **创意无限**：从光绘摄影到桌面时钟，从节奏灯到互动装置
- **社区共享**：持续更新的效果库和社区玩法分享

## 如何选择？

**选萤火虫T1，如果：**
- 你是第一次接触灯光控制器，想轻松入门
- 你需要一台随身携带、随时创作的小型设备
- 预算有限，但想体验完整的灯光创作功能

**选独角仙S1，如果：**
- 你需要长时间手持创作，手柄设计更舒适
- 你需要驱动高密度长灯带或大型灯光装置
- 你想通过 4PIN 扩展接口接入传感器，制作互动装置
