# 拓展接口

本文将介绍拓展接口 5P-PIN（上）和 5P-PIN（侧）的基本情况以及详细用法。

## 硬件介绍

萤火虫T1 目前有两个拓展接口，一个是 5PIN 接口（上方），另外一个是 5PIN 接口（左侧）。

### 5P-PIN（上）

| 引脚 | 功能 | 控制端口 |
|------|------|----------|
| PIN1 | VCC输出（5V） | GPIO43（高阻态关断，低电平接通） |
| PIN2 | GPIO | GPIO14 |
| PIN3 | GND | 直连GND |
| PIN4 | - | - |
| PIN5 | GPIO | GPIO13 |

**说明：**

- PIN1 是由一个 P-MOS 管控制的输出端口，需给 GPIO43 拉高（设置为高阻态），才会导通，并且输出 VCC 电压
- PIN3 & PIN4 是连在一起的一个端口，目的是为了加大触点的电流承载能力
- PIN2 & PIN5 是两个直连 MCU 的 GPIO 引脚，主要用来输出控制信号

**注意：**

- VCC 在使用电池供电时，需要通过电源管理(pm)主动的打开“VCC输出”，才有5V输出
- 显示屏面为“正面”，5P-PIN 的顺序为正面“从左往右”

### 5P-PIN（左侧）

| 引脚 | 功能 | 控制端口 |
|------|------|----------|
| PIN1 | VCC输出（5V） | GPIO43（高阻态关断，低电平接通） |
| PIN2 | GND | 直连GND |
| PIN3 | GPIO | GPIO42 |
| PIN4 | GPIO | GPIO15 |
| PIN5 | GPIO | GPIO16 |

**说明：**

- PIN1 是由一个 P-MOS 管控制的输出端口，需给 GPIO43 拉高（设置为高阻态），才会导通，并且输出 VCC 电压
- PIN3-PIN5 是直连 MCU 的 GPIO 引脚，主要用来输出控制信号

**注意：**

- VCC 在使用电池供电时，需要通过电源管理(pm)主动的打开“VCC输出”，才有5V输出
- 显示屏面为“正面”，5P-PIN 的顺序为正面“从上往下”

## 用法介绍

### 上方 5PIN

5PIN 接口主要是用来驱动灯光类设备，譬如结合 neopixel 库来对 ws2812 类的炫彩灯进行控制。或者通过 P-MOS 来进行大功率的调光控制。

### 侧面 5PIN

侧面 5PIN 接口主要是用来连接外设，可以以 I2C、SPI、UART 等方式连接外设设备，并且提供电源输出。当然也可以对低功率的炫彩灯进行驱动控制。
