# 店铺装修

自定义店铺前台的外观和风格。

## 选择主题

进入**在线店铺 > 主题**。Socolode 内置多款免费和付费主题，每款主题都可以先预览再启用。

### 主题设置

点击已安装主题的**自定义**按钮打开可视化编辑器，可调整：

- **颜色**：主色、辅助色、背景色和文字色
- **字体**：标题和正文的字体族、字号和字重
- **布局**：最大内容宽度、间距和网格列数
- **头部**：Logo 位置、导航样式和公告栏
- **页脚**：分栏布局、支付图标和社交链接

## 页面

在**在线店铺 > 页面**中创建自定义页面，支持富文本和 HTML。常见页面包括：

- **关于我们**：品牌故事
- **联系我们**：带邮件通知的表单
- **配送政策**：配送时效和费用
- **退换政策**：退换条件与流程

## 导航菜单

在**在线店铺 > 导航**中构建两组菜单结构。

### 主菜单

显示在头部，通常链接到：

- 商品分类（首页、女装、男装、配饰）
- 合集（新品上架、促销）
- 自定义页面（关于我们、联系我们）

### 页脚菜单

显示在页脚，通常链接到：

- 政策页面（隐私、条款、退换）
- 社交媒体主页
- 客服入口

## 自定义域名

若要使用自有域名替代 `your-store.socolode.com`：

1. 进入**设置 > 域名**
2. 点击**绑定域名**
3. 输入你的域名（如 `shop.example.com`）
4. 修改 DNS 记录：
   - 添加 **CNAME** 记录指向 `shops.socolode.com`
   - 或添加 **A** 记录指向后台显示的 IP
5. 等待 DNS 生效（最长 48 小时）

域名验证通过后，SSL 证书由 Let's Encrypt 自动签发。

## SEO 设置

每个页面和商品都有 **SEO** 区域，可设置：

- **Meta 标题**：覆盖自动生成的标题标签
- **Meta 描述**：160 字以内的搜索结果摘要
- **URL 别名**：自定义路径（如 `/products/red-sneakers`）
- **社交分享图**：链接在社交媒体分享时显示的图片

Socolode 还会自动生成 `sitemap.xml` 和 `robots.txt`。
