# 订单管理

处理、发货和跟踪客户订单。

## 订单生命周期

订单依次经历以下状态：

| 状态 | 含义 |
|------|------|
| 待处理 | 已下单，未扣款 |
| 已付款 | 已扣款，待发货 |
| 已发货 | 商品已寄出 |
| 已完成 | 订单送达并完结 |
| 已取消 | 店铺或客户取消订单 |
| 已退款 | 货款已退还客户 |

## 查看订单

进入**订单**查看所有订单。可用筛选条件：

- 状态（待处理、已付款、已发货等）
- 日期范围
- 客户姓名
- 订单金额
- 支付方式

点击任意订单查看详情：客户信息、商品明细、收货地址、支付状态和订单时间线。

## 发货

订单付款后即可发货：

1. 打开订单
2. 点击**发货**
3. 选择要发货的商品（支持部分发货）
4. 填写快递单号和承运商
5. 点击**通知客户**发送发货确认邮件

### 批量发货

高单量店铺可通过**订单 > 批量发货**上传 CSV 文件，包含列：`order_id`、`tracking_number`、`carrier`。

## 退款与退货

退款操作：

1. 打开订单
2. 点击**退款**
3. 选择全额或部分退款
4. 勾选要退款的商品和数量
5. 可选退回库存
6. 点击**确认退款**

退款将退回客户原支付方式，通常 5-10 个工作日到账。

## 修改订单

发货前可修改：

- 收货地址
- 商品和数量（增减商品）
- 运费
- 应用折扣

修改后系统重新计算订单总额，并自动向客户补扣或退还差额。

## 导出

在**订单 > 导出**中将订单导出为 CSV。可选列和日期范围，导出内容包含客户数据、商品明细、金额和发货详情，用于记账和报表。
