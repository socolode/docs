# 支付与物流

配置客户的付款方式和订单的配送方式。

## 支付网关

在**设置 > 支付**中接入一个或多个支付网关。Socolode 支持：

| 网关 | 适用地区 | 手续费 |
|------|----------|--------|
| Stripe | 全球 | 每笔 2.9% + $0.30 |
| PayPal | 全球 | 每笔 3.49% + 固定费用 |
| 支付宝 | 中国大陆 | 每笔 0.6% |
| 微信支付 | 中国大陆 | 每笔 0.6% |

### 接入网关

1. 点击网关旁的**接入**
2. 授权连接（跳转至网关页面）
3. 配置接受的货币
4. 设置交易失败时的备用网关

### 扣款模式

两种扣款模式：

- **自动扣款**：结账时立即扣款
- **手动扣款**：结账时仅预授权，发货前手动扣款

手动扣款适用于预售商品或需要发货前核实的订单。

## 物流配置

### 运费区域

在**设置 > 物流 > 区域**中创建区域，将使用相同运费的国家归为一组。

示例区域：
- **国内**：仅本国
- **亚洲**：日本、韩国、新加坡等
- **国际**：其他所有国家

### 运费规则

每个区域内可添加多种运费类型：

- **固定运费**：不论订单金额固定收费（如 ¥30）
- **按重量计费**：按总重量计算（如每公斤 ¥10）
- **满额包邮**：订单达到门槛免运费（如满 ¥199 包邮）
- **实时运费**：通过 API 从承运商获取实时报价（UPS、FedEx、DHL）

### 物流面单

在订单页面直接购买并打印面单：

1. 打开已付款订单
2. 点击**创建面单**
3. 选择承运商和服务等级
4. 确认包裹重量和尺寸
5. 打印面单（PDF 格式）

通过平台集成的承运商可享受折扣运费。

## 税务设置

在**设置 > 税务**中配置税费收取方式：

- **自动计算**：根据客户收货地址自动计算税费
- **手动设置**：为特定地区设置固定税率

可按商品开启含税定价，将税费包含在展示价格中。
