## 📦 产品详细对比

### 1. OpenStick T1 入门光绘棒（新手首选）

- **适合人群**：第一次接触光绘、预算有限、只是想玩玩拍拍日常
- **到手能用**：开箱即玩，不用组装，不用懂代码，开机就能拍
- **能做什么**：写名字、画简单图案、拍节日祝福、日常玩光绘足够用
- **特点**：性价比高，操作简单，新手第一次买不会错
- **不足**：灯珠数量少一点，复杂图案显示效果不如S1，扩展性一般

### 2. OpenStick S1 专业光绘棒（一步到位）

- **适合人群**：想认真玩光绘、拍创作/人像/商拍、想玩出更多花样
- **到手能用**：同样开箱即玩，开机就能拍
- **能做什么**：复杂高清图案、人像光绘、创意创作、商拍都能hold住
- **特点**：灯珠更密，显示效果更细腻，亮度更高，支持更多内置效果，扩展性强，一步到位不用换设备
- **不足**：价格比T1高一点

### 3. 单独控制器（萤火虫T1/独角仙S1）

- **适合人群**：喜欢DIY、会一点编程、想自己做项目、想接不同的灯条/灯板
- **注意**：单独控制器**不带灯条和外壳**，需要自己搭配配件，适合动手能力强的用户
- **能做什么**：自己接不同长度的灯条、做自定义光绘设备、二次开发、做其他创意项目（比如像素屏、氛围灯、小发明）
- **区别**：萤火虫T1是入门控制器，独角仙S1是专业控制器，性能和扩展性更强
- **不推荐**：纯新手第一次买不要单独买控制器，买成品套件更省心

### 4. LM Cam 动态光绘主机

- **适合人群**：想拍动态光绘视频、做更有创意的光绘内容
- **特点**：不是普通的光绘棒，是专门拍动态光绘的设备，可以拍出连续的动态光效
- **能做什么**：动态光绘视频、人像动态光效、创意短视频

## 🔧 配件怎么选？

配件不用一次买全，根据需要选：

1. **不同长度灯条**：想拍大字/大图案买长一点的，日常玩默认长度足够
2. **灯板**：拍特殊形状的光绘（比如爱心、星星）可以买，不是必须
3. **三脚架**：拍光绘必备，没有三脚架用东西靠住手机也能拍，有三脚架更方便
4. **延长杆**：想拍大场景/高位置的光绘可以买，不是必须
5. **电动转盘**：拍360度旋转光绘用，进阶玩家可选

:::tip 新手建议
第一次买只需要买光绘棒本体就行，配件等玩熟了知道自己需要什么再买，不用一开始买一堆。
:::

## ❓ 常见选购问题

**问：我是纯新手，买T1还是S1？**
答：预算够直接买S1，一步到位不用换；预算有限买T1，日常玩也完全够用。

**问：买了成品套件还要单独买控制器吗？**
答：不用，成品套件里已经包含控制器+灯条+外壳，到手就能用。

**问：我不会代码能玩吗？**
答：完全可以，成品套件开机就能用，内置很多图案，不用写代码也能玩的很好。

**问：手机能拍吗？一定要买相机吗？**
答：手机完全能拍，我们所有教程都是手机教程，不需要专业相机。

**问：买了之后不会用怎么办？**
答：看我们的[5分钟快速上手指南](./5-minute-quick-start.mdx)，跟着步骤来第一次就能拍成功，有问题看FAQ或者联系客服。
