# 5分钟开发者快速上手

:::note
**5分钟内就绪：** 快速开始使用烁彩代码开发平台。
:::

## 你将学到什么

- 如何搭建开发环境
- 如何为控制器刷写固件
- 如何创建你的第一个光绘脚本

## 前提条件

- ✅ 烁彩代码开发者设备（萤火虫 T1 或独角仙 S1）
- ✅ 用于连接电脑的 USB 数据线
- ✅ 基本的 Python 知识

## 快速开始命令

```bash
# 刷写固件
esptool.py --chip esp32 --port COM3 erase_flash
esptool.py --chip esp32 --port COM3 --baud 460800 write_flash -z 0x1000 firmware.bin
```

## 你的第一个脚本

```python
from machine import Pin
import time

led_pin = Pin(5, Pin.OUT)

def hello_world():
    for i in range(10):
        led_pin.on()
        time.sleep(0.1)
        led_pin.off()
        time.sleep(0.1)
    print("Hello from Socolode!")

hello_world()
```
